# Motif 1C-1 — Previews Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let developers see a design before it's built: a preview kit agents write mockups with, 8 built-in starting styles, `motif preview` (live preview in the browser plus PNGs for the record), `motif tokens --stack preview`, and `motif browser` to install a private headless browser when none is found.

**Architecture:** A small Chrome DevTools Protocol client (`browser/cdp.ts`, per decision record 0001) drives Chrome, Edge, or a Chrome for Testing headless shell that `motif browser install` downloads into `~/.motif/browsers/`. The preview kit (`skill/preview-kit/`) is plain CSS and JS that style mockups only through `--motif-*` variables and animate them with a vendored copy of Motion; the CLI embeds the kit and the 8 presets at compile time. `motif preview` serves mockups on `127.0.0.1` with live reload, injecting the theme CSS (from `design/tokens.json` or a preset) and the kit, then renders each `.mk-frame` to PNG in light and dark.

**Tech Stack:** Bun 1.4 (`Bun.serve`, `WebSocket`, text imports), TypeScript 7, `fflate` (unzip, new dependency), Motion 14 browser build (vendored, MIT), Chrome for Testing.

**Spec:** `docs/specs/2026-10-12-motif-core-design.md` — implements §9 (presets), §10.2 `preview` and `tokens --stack preview`, §10.3 (browser use), §10.4 (preview kit), §13.1 (preset snapshot tests; preview integration test), §14 (preview binds to 127.0.0.1). Follows `docs/decisions/0001-browser-control.md` (minimal CDP client).

**Split:** Part 1's former "Plan 1C" is now two plans. This one is **1C-1 Previews**. **1C-2 Screenshots and audit** (`motif shot`, `--audit`: dev-server lifecycle, route discovery, rendered contrast, target sizes, reduced motion) follows and reuses this plan's CDP client.

**Builds on:** Plans 1A and 1B (current `main`). Read `cli/src/main.ts`, `cli/src/cli/output.ts`, `cli/src/detect/browser.ts`, `cli/src/commands/tokens.ts`, `cli/src/stacks/react-web/generate.ts`, `cli/src/extract/draft.ts` before starting.

## Global Constraints

- Exit codes `0` / `1` / `2`; `--json` prints one object; plain language for people ("design guide", "theme values").
- The preview server binds to `127.0.0.1` only, serves nothing outside the project folder, and uploads nothing.
- Browser order: `MOTIF_BROWSER` (path, or `none` to disable), then system Chrome/Edge/Chromium, then the copy installed by `motif browser install`. A browser is downloaded **only** by `motif browser install`, which agents run after asking the developer; `preview` never downloads on its own.
- Chrome for Testing index: `https://googlechromelabs.github.io/chrome-for-testing/last-known-good-versions-with-downloads.json`, channel `Stable`, download kind `chrome-headless-shell`; platforms `win64`, `win32`, `mac-arm64`, `mac-x64`, `linux64`, `linux-arm64`. Installed under `<MOTIF_HOME or ~/.motif>/browsers/<version>/`, recorded in `browsers/current.json`.
- Preview kit classes start with `mk-`; frames are `.mk-frame` plus one of `.mk-phone` (390×844 screen), `.mk-tablet` (834×1194), `.mk-browser` (1440×900 window, spec §10.2). Every colour, size, font and timing in `kit.css` comes from a `--motif-*` variable, except the device bezel, which carries a `motif-ok` comment.
- Preview CSS = `motifCss(theme)` plus spring variables `--motif-spring-<name>-duration` (seconds, unitless) and `--motif-spring-<name>-bounce`.
- PNGs: one per `.mk-frame`, at 2× device scale, in light (`<name>.png`) and dark (`<name>.dark.png`), written to `design/previews/` unless `--out` says otherwise; a page without frames is captured whole. Entrance animations are skipped while rendering (reduced motion is emulated), so PNGs are deterministic.
- Presets (exactly 8): `minimal`, `soft`, `playful`, `editorial`, `bold`, `dark-tech`, `warm`, `trust`. Each folder holds `tokens.json`, `about.md`, `sample.html`, generated by `cli/scripts/build-presets.ts` and committed; every preset passes `validateTokens`, `checkRoles` and `checkContrast` with zero findings.

## Review Focus

1. **No browser at all** (fresh machine, `MOTIF_BROWSER=none`) → `preview --png-only` exits 2 with the one command to fix it; interactive `preview` still serves and opens the default browser, just without PNGs. Pinned in Task 10.
2. **Path traversal and odd URLs on the preview server** (`/../secret.txt`, `%2e%2e`, absolute paths, query strings) → never serves outside the project. Pinned in Task 8.
3. **A browser that fails to start** (sandbox restrictions on Linux, a broken binary) → a plain error naming the browser path, no hang, no orphaned process. Pinned in Task 2.
4. **Mockups with no `.mk-frame`, or several** → whole-page capture, or numbered PNGs. Pinned in Task 9.
5. **A malicious or broken zip during browser install** (`../` entries, missing binary) → nothing written outside the install folder, plain error. Pinned in Task 3.

`cli/src/browser/png.ts`:
```ts
const SIGNATURE = [137, 80, 78, 71, 13, 10, 26, 10];

/** Width and height from a PNG's IHDR chunk. */
export function pngSize(bytes: Uint8Array): { width: number; height: number } {
  if (bytes.length < 24 || !SIGNATURE.every((b, i) => bytes[i] === b)) throw new Error("Not a PNG image.");
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  return { width: view.getUint32(16), height: view.getUint32(20) };
}
```

`cli/src/browser/cdp.ts`:
```ts
import { spawn, type ChildProcess } from "node:child_process";
import { mkdtempSync, rmSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";

export interface Clip {
  x: number;
  y: number;
  width: number;
  height: number;
}

export interface Page {
  setViewport(width: number, height: number, scale?: number, mobile?: boolean): Promise<void>;
  emulateMedia(features: { name: string; value: string }[]): Promise<void>;
  goto(url: string, timeoutMs?: number): Promise<void>;
  evaluate<T = unknown>(expression: string): Promise<T>;
  screenshot(clip?: Clip): Promise<Uint8Array>;
  close(): Promise<void>;
}

export interface Browser {
  newPage(): Promise<Page>;
  close(): Promise<void>;
}

interface Message {
  id?: number;
  method?: string;
  sessionId?: string;
  result?: any;
  error?: { message: string };
}

const ARGS = [
  "--headless=new", "--remote-debugging-port=0", "--no-first-run", "--no-default-browser-check", "--disable-gpu",
  "--hide-scrollbars", "--mute-audio", "--disable-extensions", "--disable-background-networking", "--disable-sync",
  "--force-color-profile=srgb",
];

class StartError extends Error {
  constructor(message: string, readonly stderr: string) {
    super(message);
  }
}

function start(executable: string, args: string[], timeoutMs: number): Promise<{ proc: ChildProcess; wsUrl: string; profile: string }> {
  const profile = mkdtempSync(join(tmpdir(), "motif-browser-"));
  const cleanup = () => rmSync(profile, { recursive: true, force: true, maxRetries: 5, retryDelay: 100 });
  return new Promise((resolve, reject) => {
    let stderr = "";
    let settled = false;
    const fail = (err: Error) => {
      if (settled) return;
      settled = true;
      clearTimeout(timer);
      if (proc.exitCode === null) proc.kill();
      cleanup();
      reject(err);
    };
    const proc = spawn(executable, [...args, `--user-data-dir=${profile}`, "about:blank"], { stdio: ["ignore", "ignore", "pipe"] });
    const timer = setTimeout(() => fail(new StartError(`The browser at ${executable} didn't start within ${Math.round(timeoutMs / 1000)} s.`, stderr)), timeoutMs);
    proc.stderr!.on("data", (chunk) => {
      stderr += chunk.toString();
      const m = stderr.match(/DevTools listening on (ws:\/\/\S+)/);
      if (m && !settled) {
        settled = true;
        clearTimeout(timer);
        resolve({ proc, wsUrl: m[1]!, profile });
      }
    });
    proc.on("error", (e) => fail(new StartError(`Couldn't start the browser at ${executable}: ${e.message}`, stderr)));
    proc.on("exit", (code) => fail(new StartError(`The browser at ${executable} stopped while starting (exit code ${code}).`, stderr)));
  });
}

export async function launchBrowser(executable: string, opts: { timeoutMs?: number } = {}): Promise<Browser> {
  const timeoutMs = opts.timeoutMs ?? 20_000;
  let started;
  try {
    started = await start(executable, ARGS, timeoutMs);
  } catch (e) {
    // Some Linux setups block Chrome's sandbox for unprivileged users; retry once without it.
    if (process.platform === "linux" && e instanceof StartError && /sandbox/i.test(e.stderr)) {
      started = await start(executable, [...ARGS, "--no-sandbox"], timeoutMs);
    } else {
      throw e;
    }
  }
  const { proc, wsUrl, profile } = started;

  const ws = new WebSocket(wsUrl);
  await new Promise<void>((resolve, reject) => {
    ws.addEventListener("open", () => resolve(), { once: true });
    ws.addEventListener("error", () => reject(new Error(`Couldn't connect to the browser at ${executable}.`)), { once: true });
  });

  let nextId = 1;
  const pending = new Map<number, { resolve: (v: any) => void; reject: (e: Error) => void }>();
  const listeners = new Set<(m: Message) => void>();
  ws.addEventListener("message", (event) => {
    const msg = JSON.parse(String(event.data)) as Message;
    if (msg.id !== undefined && pending.has(msg.id)) {
      const p = pending.get(msg.id)!;
      pending.delete(msg.id);
      if (msg.error) p.reject(new Error(msg.error.message));
      else p.resolve(msg.result);
    } else {
      for (const l of listeners) l(msg);
    }
  });

  const send = (method: string, params: object = {}, sessionId?: string): Promise<any> => {
    const id = nextId++;
    ws.send(JSON.stringify({ id, method, params, ...(sessionId ? { sessionId } : {}) }));
    return new Promise((resolve, reject) => pending.set(id, { resolve, reject }));
  };

  const waitFor = (sessionId: string, method: string, timeoutMs: number) =>
    new Promise<void>((resolve, reject) => {
      const listener = (m: Message) => {
        if (m.sessionId === sessionId && m.method === method) {
          listeners.delete(listener);
          clearTimeout(timer);
          resolve();
        }
      };
      const timer = setTimeout(() => {
        listeners.delete(listener);
        reject(new Error("The page took too long to load."));
      }, timeoutMs);
      listeners.add(listener);
    });

  return {
    async newPage(): Promise<Page> {
      const { targetId } = await send("Target.createTarget", { url: "about:blank" });
      const { sessionId } = await send("Target.attachToTarget", { targetId, flatten: true });
      await send("Page.enable", {}, sessionId);
      await send("Runtime.enable", {}, sessionId);
      return {
        async setViewport(width, height, scale = 1, mobile = false) {
          await send("Emulation.setDeviceMetricsOverride", { width, height, deviceScaleFactor: scale, mobile }, sessionId);
        },
        async emulateMedia(features) {
          await send("Emulation.setEmulatedMedia", { features }, sessionId);
        },
        async goto(url, timeoutMs = 30_000) {
          const loaded = waitFor(sessionId, "Page.loadEventFired", timeoutMs);
          const r = await send("Page.navigate", { url }, sessionId);
          if (r.errorText) {
            loaded.catch(() => {});
            throw new Error(`Couldn't open ${url}: ${r.errorText}`);
          }
          await loaded;
        },
        async evaluate<T>(expression: string): Promise<T> {
          const r = await send("Runtime.evaluate", { expression, awaitPromise: true, returnByValue: true }, sessionId);
          if (r.exceptionDetails) {
            throw new Error(`Script error in the page: ${r.exceptionDetails.exception?.description ?? r.exceptionDetails.text}`);
          }
          return r.result.value as T;
        },
        async screenshot(clip) {
          const params = clip ? { format: "png", captureBeyondViewport: true, clip: { ...clip, scale: 1 } } : { format: "png" };
          const r = await send("Page.captureScreenshot", params, sessionId);
          return new Uint8Array(Buffer.from(r.data, "base64"));
        },
        async close() {
          await send("Target.closeTarget", { targetId });
        },
      };
    },
    async close() {
      try {
        await Promise.race([send("Browser.close"), new Promise((r) => setTimeout(r, 2000))]);
      } catch {
        // The browser may already be gone.
      }
      ws.close();
      if (proc.exitCode === null) proc.kill();
      await new Promise((r) => (proc.exitCode !== null ? r(null) : proc.once("exit", r)));
      rmSync(profile, { recursive: true, force: true, maxRetries: 5, retryDelay: 100 });
    },
  };
}
```

```ts
import { chmodSync, existsSync, mkdirSync, readFileSync, rmSync, writeFileSync } from "node:fs";
import { dirname, join, normalize, sep } from "node:path";
import { unzipSync } from "fflate";

export const BROWSER_INDEX_URL = "https://googlechromelabs.github.io/chrome-for-testing/last-known-good-versions-with-downloads.json";

/** Chrome for Testing's platform name for this system, or null when it has no build. */
export function cftPlatform(platform: NodeJS.Platform = process.platform, arch: string = process.arch): string | null {
  if (platform === "win32") return arch === "ia32" ? "win32" : "win64";
  if (platform === "darwin") return arch === "arm64" ? "mac-arm64" : "mac-x64";
  if (platform === "linux") return arch === "arm64" ? "linux-arm64" : "linux64";
  return null;
}

const browsersDir = (home: string) => join(home, "browsers");

export function installedBrowser(home: string): string | null {
  try {
    const { path } = JSON.parse(readFileSync(join(browsersDir(home), "current.json"), "utf8"));
    return typeof path === "string" && existsSync(path) ? path : null;
  } catch {
    return null;
  }
}

export async function installBrowser(opts: { home: string; indexUrl?: string; platform?: NodeJS.Platform; arch?: string }): Promise<{ version: string; path: string; bytes: number }> {
  const platform = opts.platform ?? process.platform;
  const plat = cftPlatform(platform, opts.arch ?? process.arch);
  if (!plat) throw new Error(`Motif can't download a browser for this system (${platform}). Install Chrome or Chromium instead.`);

  const indexRes = await fetch(opts.indexUrl ?? BROWSER_INDEX_URL).catch(() => null);
  if (!indexRes?.ok) throw new Error(`Couldn't reach the Chrome for Testing download list${indexRes ? ` (HTTP ${indexRes.status})` : ""}. Check your internet connection and try again.`);
  const index = (await indexRes.json()) as any;
  const stable = index?.channels?.Stable;
  const url: string | undefined = stable?.downloads?.["chrome-headless-shell"]?.find((d: any) => d.platform === plat)?.url;
  if (!stable?.version || !url) throw new Error(`The Chrome for Testing download list has no headless browser for ${plat}.`);

  const zipRes = await fetch(url).catch(() => null);
  if (!zipRes?.ok) throw new Error(`Couldn't download the browser${zipRes ? ` (HTTP ${zipRes.status})` : ""}. Try again later.`);
  const bytes = new Uint8Array(await zipRes.arrayBuffer());
  let entries: Record<string, Uint8Array>;
  try {
    entries = unzipSync(bytes);
  } catch {
    throw new Error("The downloaded browser archive is damaged. Try again.");
  }

  const dir = join(browsersDir(opts.home), String(stable.version));
  rmSync(dir, { recursive: true, force: true });
  const root = normalize(dir) + sep;
  for (const [name, data] of Object.entries(entries)) {
    if (name.endsWith("/")) continue;
    const target = normalize(join(dir, name));
    if (!target.startsWith(root)) continue; // never write outside the install folder
    mkdirSync(dirname(target), { recursive: true });
    writeFileSync(target, data);
    if (platform !== "win32") chmodSync(target, 0o755);
  }
  const exe = join(dir, `chrome-headless-shell-${plat}`, platform === "win32" ? "chrome-headless-shell.exe" : "chrome-headless-shell");
  if (!existsSync(exe)) throw new Error(`The downloaded archive doesn't contain the browser (${exe}).`);
  writeFileSync(join(browsersDir(opts.home), "current.json"), JSON.stringify({ version: stable.version, path: exe }, null, 2) + "\n");
  return { version: String(stable.version), path: exe, bytes: bytes.length };
}
```

```ts
import { installBrowser } from "../browser/install";
import type { CommandResult, RunContext } from "../cli/output";
import { findBrowser, type BrowserInfo } from "../detect/browser";
import { motifHome } from "../home";

export interface BrowserDeps {
  find: () => BrowserInfo | null;
  install: () => Promise<{ version: string; path: string; bytes: number }>;
}

const defaultDeps: BrowserDeps = { find: () => findBrowser(), install: () => installBrowser({ home: motifHome() }) };

export async function runBrowser(_cwd: string, ctx: RunContext, deps: BrowserDeps = defaultDeps): Promise<CommandResult> {
  const action = ctx.positionals[0];
  if (!action) {
    const browser = deps.find();
    return browser
      ? { command: "browser", exitCode: 0, text: `✓ Previews and screenshots use ${browser.name}: ${browser.path}`, data: { browser } }
      : {
          command: "browser",
          exitCode: 0,
          text: 'No Chrome or Edge found. "motif browser install" downloads a private headless copy (about 100 MB) that only Motif uses.',
          data: { browser: null },
        };
  }
  if (action !== "install") {
    return { command: "browser", exitCode: 2, text: `Unknown action "${action}". Use "motif browser" or "motif browser install".`, data: { error: "usage" } };
  }
  try {
    const r = await deps.install();
    return {
      command: "browser",
      exitCode: 0,
      text: `✓ Installed a private headless browser (Chrome for Testing ${r.version}) for previews and screenshots.\n  ${r.path}`,
      data: { version: r.version, path: r.path, bytes: r.bytes },
    };
  } catch (e) {
    return { command: "browser", exitCode: 2, text: e instanceof Error ? e.message : String(e), data: { error: "install-failed" } };
  }
}
```

```js
// Motif preview kit: live reload while previewing, and motion from the design guide's springs.
(function () {
  "use strict";
  var css = getComputedStyle(document.documentElement);
  function num(name, fallback) {
    var v = parseFloat(css.getPropertyValue(name));
    return isFinite(v) ? v : fallback;
  }
  function spring(name) {
    return { type: "spring", visualDuration: num("--motif-spring-" + name + "-duration", 0.4), bounce: num("--motif-spring-" + name + "-bounce", 0.1) };
  }

  // Reload when a mockup changes (only when served by `motif preview`).
  if (location.protocol.indexOf("http") === 0 && "EventSource" in window) {
    try {
      new EventSource("/__motif/events").addEventListener("reload", function () { location.reload(); });
    } catch (e) { /* no live reload */ }
  }

  var M = window.Motion;
  if (!M || matchMedia("(prefers-reduced-motion: reduce)").matches) return;

  function start() {
    var entering = document.querySelectorAll("[data-enter]");
    for (var i = 0; i < entering.length; i++) {
      var el = entering[i];
      var kind = el.getAttribute("data-enter") || "rise";
      var from = kind === "fade" ? { opacity: [0, 1] }
        : kind === "scale" ? { opacity: [0, 1], scale: [0.96, 1] }
        : { opacity: [0, 1], y: [12, 0] };
      var options = spring("smooth");
      options.delay = i * 0.04;
      M.animate(el, from, options);
    }
    var pressable = document.querySelectorAll(".mk-btn, .mk-row, .mk-tab, .mk-nav-item, [data-press]");
    for (var j = 0; j < pressable.length; j++) {
      M.press(pressable[j], function (target) {
        M.animate(target, { scale: 0.97 }, spring("snappy"));
        return function () { M.animate(target, { scale: 1 }, spring("snappy")); };
      });
    }
  }
  if (document.readyState === "loading") document.addEventListener("DOMContentLoaded", start);
  else start();
})();
```

````markdown
# Motif preview kit

Mockups are plain HTML that use these classes. They never contain colours, sizes, fonts or timings of their own: everything comes from the design guide's `--motif-*` variables, so a mockup always shows the current design.

## With the tool (normal)

Write the screen into `design/previews/<name>.html`, then run `motif preview design/previews/<name>.html`. The tool serves it, adds the theme and this kit, reloads on save, and writes PNGs (light and dark) next to it.

## Without the tool

Copy `kit.css`, `kit.js` and `vendor/motion.js` next to the mockup, write the theme variables yourself into a `<style>` block (one `--motif-*` variable per role in `design/tokens.json`), link the files in `<head>`, and open the HTML file directly. There is no live reload and no PNG.

## Frames

- `.mk-stage` — page layout for one or more frames
- `.mk-frame` — every device; add one of `.mk-phone` (with `.mk-ios` or `.mk-android`), `.mk-tablet`, `.mk-browser`
- Phone parts, top to bottom: `.mk-status`, your screen, `.mk-home` (iOS)
- Browser parts: `.mk-toolbar` containing `.mk-address`, then `.mk-body-row` with `.mk-sidebar` and `.mk-main`

## Layout and type

`.mk-screen` (scrolling content area), `.mk-pad`, `.mk-stack`, `.mk-row-inline`, `.mk-grow` · `.mk-display`, `.mk-title`, `.mk-heading`, `.mk-body`, `.mk-label`, `.mk-caption`, `.mk-muted`

## Components

`.mk-btn` (with `.mk-secondary`, `.mk-ghost`, `.mk-block`) · `.mk-field` with a `label` and `.mk-input`, `.mk-hint`, `.mk-error-text` · `.mk-card` · `.mk-list` of `.mk-row` · `.mk-avatar` · `.mk-badge` (with `.mk-success`, `.mk-warning`, `.mk-danger`, `.mk-info`) · `.mk-icon` · `.mk-divider` · `.mk-topbar` · `.mk-tabbar` of `.mk-tab` (`.mk-active`) · `.mk-sidebar` of `.mk-nav-item` (`.mk-active`) · `.mk-scrim`, `.mk-sheet`, `.mk-dialog`, `.mk-toast` · `.mk-skeleton` · `.mk-empty`

## Motion

Add `data-enter="rise"` (or `fade`, `scale`) to animate an element in with the guide's `smooth` spring; buttons, rows, tabs and nav items get press feedback with the `snappy` spring. Motion is skipped when the viewer prefers reduced motion. Show every state a screen needs (loading with `.mk-skeleton`, empty with `.mk-empty`, errors with `.mk-error-text` or a `.mk-toast`) as separate frames.
````

```ts
export function defaultShadows(): Record<string, unknown> {
  const shadow = (y: number, blur: number, alpha: number) => ({
    $value: { color: { colorSpace: "srgb", components: [0, 0, 0], alpha, hex: "#000000" }, offsetX: px(0), offsetY: px(y), blur: px(blur), spread: px(0) },
  });

}

    duration: { $type: "duration", $value: { value: duration, unit: "s" } },
    bounce: { $type: "number", $value: bounce },
  };
}

  return STANDARD_PAIRS.map(([fg, bg, kind]) => ({ fg: `color.${fg}`, bg: `color.${bg}`, kind }));
```

```ts
import { wcagContrast } from "culori";
import { FONT_ROLES, SPACE_SCALE, defaultShadows, ms, pairsExtension, px, springGroup, srgbColor } from "../contract/defaults";
import type { PaletteRole, PresetSpec } from "./spec";

const ON_BASES = ["action-primary", "action-secondary", "success", "warning", "danger", "info"] as const;
const DISPLAY_ROLES = new Set(["display", "title", "heading"]);

export function presetTokens(spec: PresetSpec): Record<string, unknown> {
  const primitives: Record<string, unknown> = { $type: "color" };
  const color: Record<string, unknown> = { $type: "color" };
  const inks = [spec.light["text-primary"], spec.dark["text-primary"], "#FFFFFF"];
  const onFor = (base: string) => inks.reduce((best, c) => (wcagContrast(c, base) > wcagContrast(best, base) ? c : best));
  const primitive = (name: string, hex: string) => {
    primitives[name] = { $value: srgbColor(hex) };
    return `{primitive.color.${name}}`;
  };
  const role = (name: string, light: string, dark: string) => {
    color[name] = {
      $value: primitive(`light-${name}`, light),
      $extensions: { "dev.motif": { modes: { dark: primitive(`dark-${name}`, dark) } } },
    };
  };
  for (const r of Object.keys(spec.light) as PaletteRole[]) role(r, spec.light[r], spec.dark[r]);
  role("text-inverse", spec.light.surface, spec.dark.background);
  for (const base of ON_BASES) role(`on-${base}`, onFor(spec.light[base]), onFor(spec.dark[base]));

  const font: Record<string, unknown> = { $type: "typography" };
  for (const [name, weight, lineHeight] of FONT_ROLES) {
    font[name] = {
      $value: {
        fontFamily: DISPLAY_ROLES.has(name) ? "{primitive.font.display}" : "{primitive.font.sans}",
        fontSize: px(spec.sizes[name as keyof PresetSpec["sizes"]]),
        fontWeight: weight,
        lineHeight,
      },
    };
  }
  const space: Record<string, unknown> = { $type: "dimension" };
  for (const [key, value] of SPACE_SCALE) space[key] = { $value: px(value) };

  return {
    $extensions: { "dev.motif": { motifContract: 1, preset: spec.id, pairs: pairsExtension() } },
    primitive: {
      color: primitives,
      font: {
        sans: { $type: "fontFamily", $value: spec.fonts.body },
        display: { $type: "fontFamily", $value: spec.fonts.display },
      },
    },
    color,
    font,
    space,
    radius: {
      $type: "dimension",
      none: { $value: px(0) },
      sm: { $value: px(spec.radius.sm) },
      md: { $value: px(spec.radius.md) },
      lg: { $value: px(spec.radius.lg) },
      full: { $value: px(9999) },
    },
    shadow: defaultShadows(),
    duration: {
      $type: "duration",
      instant: { $value: ms(0) },
      fast: { $value: ms(spec.durations.fast) },
      base: { $value: ms(spec.durations.base) },
      slow: { $value: ms(spec.durations.slow) },
    },
    easing: { $type: "cubicBezier", standard: { $value: spec.easing }, enter: { $value: [0, 0, 0, 1] }, exit: { $value: [0.3, 0, 1, 1] } },
    spring: {
      snappy: springGroup(...spec.springs.snappy),
      smooth: springGroup(...spec.springs.smooth),
      bouncy: springGroup(...spec.springs.bouncy),
    },
  };
}

export function presetAbout(spec: PresetSpec): string {
  const fonts = spec.fonts.display[0] === spec.fonts.body[0]
    ? `${spec.fonts.body[0]} throughout`
    : `${spec.fonts.display[0]} for headings, ${spec.fonts.body[0]} for text`;
  return [
    `# ${spec.title}`,
    "",
    `**Feels:** ${spec.words.join(", ")}`,
    "",
    `**Best for:** ${spec.bestFor}`,
    "",
    `**Avoid for:** ${spec.avoidFor}`,
    "",
    `**Fonts:** ${fonts} · **Corners:** ${spec.radius.sm} / ${spec.radius.md} / ${spec.radius.lg} px · **Motion:** ${spec.motionNote}`,
    "",
  ].join("\n");
}

export function presetSample(spec: PresetSpec, template: string): string {
  return template.replace(/\r\n/g, "\n").replace("<title>Motif mockup</title>", `<title>${spec.title} — Motif</title>`);
}
```

```ts
import { existsSync, readFileSync, statSync, watch, type FSWatcher } from "node:fs";
import { dirname, extname, isAbsolute, relative, resolve, sep } from "node:path";
import { previewCss } from "../generate/preview-css";
import type { Theme } from "../generate/theme";
import { KIT_ASSETS, TEMPLATE_HTML } from "./assets";
import { comparePage, galleryPage } from "./pages";
import { EMBEDDED_PRESETS, presetTheme } from "./presets";

export interface PreviewServer {
  url: string;
  port: number;
  stop(): void;
}

const TYPES: Record<string, string> = {
  ".html": "text/html; charset=utf-8", ".css": "text/css; charset=utf-8", ".js": "text/javascript; charset=utf-8",
  ".json": "application/json", ".svg": "image/svg+xml", ".png": "image/png", ".jpg": "image/jpeg", ".jpeg": "image/jpeg",
  ".webp": "image/webp", ".gif": "image/gif", ".woff2": "font/woff2", ".woff": "font/woff",
};

export function injectKit(html: string, themeHref: string): string {
  const tags = [
    `<link rel="stylesheet" href="${themeHref}">`,
    '<link rel="stylesheet" href="/__motif/kit/kit.css">',
    '<script src="/__motif/kit/vendor/motion.js"></script>',
    '<script src="/__motif/kit/kit.js"></script>',
  ].join("\n");
  return /<\/head>/i.test(html) ? html.replace(/<\/head>/i, `${tags}\n</head>`) : `${tags}\n${html}`;
}

/** The file a request path names, or null if it would leave the project folder. */
export function resolveInside(root: string, urlPath: string): string | null {
  let decoded: string;
  try {
    decoded = decodeURIComponent(urlPath);
  } catch {
    return null;
  }
  if (decoded.includes("\0")) return null;
  const target = resolve(root, "." + (decoded.startsWith("/") ? decoded : `/${decoded}`));
  const rel = relative(root, target);
  return rel.split(sep)[0] === ".." || isAbsolute(rel) ? null : target;
}

const notFound = () => new Response("Not found", { status: 404 });

export function startPreviewServer(opts: { root: string; theme: Theme | null; watch?: string[] }): PreviewServer {
  const root = resolve(opts.root);
  const encoder = new TextEncoder();
  const clients = new Set<ReadableStreamDefaultController<Uint8Array>>();
  const html = (body: string) => new Response(body, { headers: { "content-type": TYPES[".html"]!, "cache-control": "no-store" } });
  const themeCss = (preset: string | null) => {
    const theme = preset ? presetTheme(preset) : opts.theme;
    return theme ? previewCss(theme) : "/* No design guide yet: use --preset <name>, or write design/tokens.json. */\n";
  };

  const server = Bun.serve({
    hostname: "127.0.0.1",
    port: 0,
    fetch(req, srv) {
      const url = new URL(req.url);
      const path = url.pathname;
      if (path === "/__motif/theme.css") {
        return new Response(themeCss(url.searchParams.get("preset")), { headers: { "content-type": TYPES[".css"]!, "cache-control": "no-store" } });
      }
      if (path.startsWith("/__motif/kit/")) {
        const name = path.slice("/__motif/kit/".length);
        if (!Object.hasOwn(KIT_ASSETS, name)) return notFound();
        const asset = KIT_ASSETS[name as keyof typeof KIT_ASSETS];
        return new Response(asset.body, { headers: { "content-type": asset.type } });
      }
      if (path === "/__motif/events") {
        srv.timeout(req, 0); // keep the event stream open
        let controller!: ReadableStreamDefaultController<Uint8Array>;
        const stream = new ReadableStream<Uint8Array>({
          start(c) {
            controller = c;
            clients.add(c);
            c.enqueue(encoder.encode(": connected\n\n"));
          },
          cancel() {
            clients.delete(controller);
          },
        });
        return new Response(stream, { headers: { "content-type": "text/event-stream", "cache-control": "no-store" } });
      }
      if (path === "/__motif/compare") return html(comparePage(url.searchParams.getAll("f")));
      if (path === "/__motif/gallery") return html(galleryPage(EMBEDDED_PRESETS));
      const sample = path.match(/^\/__motif\/preset\/([a-z-]+)\/sample\.html$/);
      if (sample) {
        return presetTheme(sample[1]!) ? html(injectKit(TEMPLATE_HTML, `/__motif/theme.css?preset=${sample[1]}`)) : notFound();
      }
      const file = resolveInside(root, path);
      if (!file || !existsSync(file) || !statSync(file).isFile()) return notFound();
      const ext = extname(file).toLowerCase();
      if (ext === ".html") return html(injectKit(readFileSync(file, "utf8"), "/__motif/theme.css"));
      return new Response(Bun.file(file), { headers: { "content-type": TYPES[ext] ?? "application/octet-stream" } });
    },
  });

  // Live reload: watch the folders of the mockups being previewed.
  const watchers: FSWatcher[] = [];
  let timer: ReturnType<typeof setTimeout> | undefined;
  const notify = () => {
    clearTimeout(timer);
    timer = setTimeout(() => {
      for (const c of clients) {
        try {
          c.enqueue(encoder.encode("event: reload\ndata: 1\n\n"));
        } catch {
          clients.delete(c);
        }
      }
    }, 100);
  };
  for (const dir of new Set((opts.watch ?? []).map((f) => dirname(resolve(root, f))))) {
    try {
      watchers.push(watch(dir, notify));
    } catch {
      // Live reload is a convenience; previews still work without it.
    }
  }

  return {
    url: `http://127.0.0.1:${server.port}`,
    port: server.port!,
    stop() {
      clearTimeout(timer);
      for (const w of watchers) w.close();
      for (const c of clients) {
        try {
          c.close();
        } catch {
          // already closed
        }
      }
      server.stop(true);
    },
  };
}
```

```ts
import { mkdirSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { launchBrowser, type Clip } from "../browser/cdp";

export interface RenderTarget {
  url: string;
  name: string;
}

const VIEWPORT = { width: 1600, height: 1200, scale: 2 };
const SCHEMES = ["light", "dark"] as const;

// Page-relative boxes of the visible frames (scroll offsets added, so frames below the fold are found too).
const FRAMES = `[...document.querySelectorAll(".mk-frame")]
  .map((e) => { const r = e.getBoundingClientRect(); return { x: r.left + scrollX, y: r.top + scrollY, width: r.width, height: r.height }; })
  .filter((r) => r.width > 0 && r.height > 0)`;
const WHOLE_PAGE = `({ x: 0, y: 0, width: document.documentElement.scrollWidth, height: document.documentElement.scrollHeight })`;

export function pngName(name: string, index: number, scheme: "light" | "dark"): string {
  return `${name}${index > 0 ? `-${index + 1}` : ""}${scheme === "dark" ? ".dark" : ""}.png`;
}

/** Renders each target in light and dark, one PNG per frame. Starts the browser once. */
export async function renderPngs(opts: { browserPath: string; targets: RenderTarget[]; outDir: string; timeoutMs?: number }): Promise<string[]> {
  const browser = await launchBrowser(opts.browserPath, { timeoutMs: opts.timeoutMs });
  const written: string[] = [];
  try {
    const page = await browser.newPage();
    await page.setViewport(VIEWPORT.width, VIEWPORT.height, VIEWPORT.scale);
    mkdirSync(opts.outDir, { recursive: true });
    for (const target of opts.targets) {
      for (const scheme of SCHEMES) {
        await page.emulateMedia([
          { name: "prefers-color-scheme", value: scheme },
          { name: "prefers-reduced-motion", value: "reduce" },
        ]);
        await page.goto(target.url, opts.timeoutMs);
        await page.evaluate("document.fonts.ready.then(() => true)");
        const frames = await page.evaluate<Clip[]>(FRAMES);
        const clips = frames.length > 0 ? frames : [await page.evaluate<Clip>(WHOLE_PAGE)];
        for (const [i, clip] of clips.entries()) {
          const file = join(opts.outDir, pngName(target.name, i, scheme));
          writeFileSync(file, await page.screenshot(clip));
          written.push(file);
        }
      }
    }
  } finally {
    await browser.close();
  }
  return written;
}
```

```ts
import { spawn } from "node:child_process";

/** The program that opens a web address in the default browser. The address is one argument, never parsed by a shell. */
export function openCommand(url: string, platform: NodeJS.Platform = process.platform): [string, string[]] {
  if (platform === "win32") return ["rundll32", ["url.dll,FileProtocolHandler", url]];
  if (platform === "darwin") return ["open", [url]];
  return ["xdg-open", [url]];
}

/** Opens url in the default browser. Resolves false if that couldn't be started. */
export function openUrl(url: string): Promise<boolean> {
  const [cmd, args] = openCommand(url);
  return new Promise((resolve) => {
    try {
      const child = spawn(cmd, args, { stdio: "ignore", detached: true });
      child.once("error", () => resolve(false));
      child.once("spawn", () => {
        child.unref();
        resolve(true);
      });
    } catch {
      resolve(false);
    }
  });
}
```

```ts
import { buildTheme, type Theme } from "../generate/theme";
import { openUrl } from "../preview/open";
import { EMBEDDED_PRESETS, presetTheme } from "../preview/presets";
import { renderPngs, type RenderTarget } from "../preview/render";
import { startPreviewServer } from "../preview/server";
import { TOKENS_JSON } from "./validate";

export interface PreviewDeps {
  findBrowser: () => BrowserInfo | null;
  render: typeof renderPngs;
  openUrl: (url: string) => Promise<boolean>;
  waitForStop: () => Promise<void>;
}

const defaultDeps: PreviewDeps = {
  findBrowser: () => findBrowser(),
  render: renderPngs,
  openUrl,
  waitForStop: () =>
    new Promise((resolve) => {
      process.once("SIGINT", () => resolve());
      process.once("SIGTERM", () => resolve());
    }),
};

const PRESET_IDS = EMBEDDED_PRESETS.map((p) => p.id);
const INSTALL_HINT = '"motif browser install" downloads a private headless copy (about 100 MB) that only Motif uses.';

const fail = (exitCode: 1 | 2, text: string, data: Record<string, unknown>): CommandResult => ({ command: "preview", exitCode, text, data });
const projectPath = (cwd: string, abs: string) => relative(cwd, abs).split(sep).join("/");
const urlPath = (rel: string) => "/" + rel.split("/").map(encodeURIComponent).join("/");
const isHtml = (name: string) => name.toLowerCase().endsWith(".html");

/** The mockups named on the command line (files or folders of .html files), as project paths. */
function collectFiles(cwd: string, args: string[]): { files: string[] } | { error: string } {
  const files: string[] = [];
  for (const arg of args) {
    const abs = resolve(cwd, arg);
    const rel = relative(cwd, abs);
    if (rel.split(sep)[0] === ".." || isAbsolute(rel)) {
      return { error: `${arg} is outside this folder. Previews only serve files inside the project (use --cwd to preview another one).` };
    }
    if (!existsSync(abs)) return { error: `Couldn't find ${arg}.` };
    if (statSync(abs).isDirectory()) {
      const pages = readdirSync(abs).filter(isHtml).sort();
      if (pages.length === 0) return { error: `${arg} has no .html mockups.` };
      files.push(...pages.map((p) => projectPath(cwd, join(abs, p))));
    } else if (!isHtml(abs)) {
      return { error: `${arg} isn't an .html mockup.` };
    } else {
      files.push(projectPath(cwd, abs));
    }
  }
  return { files: [...new Set(files)] };
}

/** PNG base names: the file name, or the whole path when two mockups share a file name. */
function pngNames(files: string[]): string[] {
  const base = files.map((f) => basename(f).replace(/\.html$/i, ""));
  return files.map((f, i) =>
    base.filter((b) => b === base[i]).length > 1 ? f.replace(/\.html$/i, "").replace(/\//g, "-") : base[i]!,
  );
}

function contractTheme(cwd: string): { theme: Theme | null; problems: Finding[] } {
  const path = join(cwd, "design", "tokens.json");
  if (!existsSync(path)) return { theme: null, problems: [] };
  const { doc, findings } = loadTokenDocument(TOKENS_JSON, readFileSync(path, "utf8"));
  const problems = doc ? [...findings, ...validateTokens(doc), ...checkRoles(doc)].filter((f) => f.severity === "error") : findings;
  return { theme: doc && problems.length === 0 ? buildTheme(doc) : null, problems };
}

export async function runPreview(cwd: string, ctx: RunContext, deps: PreviewDeps = defaultDeps): Promise<CommandResult> {
  const flags = ctx.flags ?? {};
  const gallery = flags.gallery === true;
  const compare = flags.compare === true;
  const pngOnly = flags["png-only"] === true;
  const preset = typeof flags.preset === "string" ? flags.preset : undefined;

  if (gallery && ctx.positionals.length > 0) {
    return fail(2, "--gallery shows the 8 starting styles on its own; leave out the file names.", { error: "usage" });
  }
  if (!gallery && ctx.positionals.length === 0) {
    return fail(2, "Name the mockups to preview, e.g. motif preview design/previews/home.html (or a folder of them).\nTo see the 8 starting styles instead: motif preview --gallery", { error: "usage" });
  }
  const collected = collectFiles(cwd, ctx.positionals);
  if ("error" in collected) return fail(2, collected.error, { error: "bad-file" });
  const files = collected.files;
  if (compare && files.length < 2) return fail(2, "--compare needs at least two mockups (or a folder with two or more).", { error: "usage" });

  let theme: Theme | null = null;
  if (preset !== undefined) {
    theme = presetTheme(preset);
    if (!theme) return fail(2, `There's no starting style called "${preset}". Choose one of: ${PRESET_IDS.join(", ")}.`, { error: "no-such-preset" });
  } else if (!gallery) {
    const loaded = contractTheme(cwd);
    if (loaded.problems.length > 0) {
      const n = loaded.problems.length;
      return fail(
        1,
        `✗ Your theme values have ${n} ${n === 1 ? "problem" : "problems"}, so the preview would be wrong:\n${formatFindings(loaded.problems)}\nFix these first (motif validate shows details).`,
        { error: "invalid-contract", findings: loaded.problems },
      );
    }
    if (!loaded.theme) {
      return fail(2, "No design guide found in this folder (missing design/tokens.json).\nPreview with a starting style instead: --preset <name> (motif preview --gallery shows all 8).", { error: "no-contract" });
    }
    theme = loaded.theme;
  }

  const browser = deps.findBrowser();
  if (pngOnly && !browser) {
    return fail(2, `No Chrome or Edge found, so Motif can't make PNGs. ${INSTALL_HINT}`, { error: "needs-browser", status: "needs_browser" });
  }

  const server = startPreviewServer({ root: cwd, theme, watch: pngOnly ? [] : files });
  const outDir = resolve(cwd, typeof flags.out === "string" ? flags.out : join("design", "previews"));
  const names = pngNames(files);
  const targets: RenderTarget[] = gallery
    ? PRESET_IDS.map((id) => ({ name: `preset-${id}`, url: `${server.url}/__motif/preset/${id}/sample.html` }))
    : files.map((f, i) => ({ name: names[i]!, url: server.url + urlPath(f) }));

  const notes: string[] = [];
  let pngs: string[] = [];
  if (browser) {
    try {
      pngs = (await deps.render({ browserPath: browser.path, targets, outDir })).map((p) => projectPath(cwd, p));
    } catch (e) {
      const message = e instanceof Error ? e.message : String(e);
      if (pngOnly) {
        server.stop();
        return fail(2, `Couldn't make PNGs: ${message}`, { error: "render-failed", message });
      }
      notes.push(`Couldn't make PNGs: ${message}`);
    }
  } else {
    notes.push(`No Chrome or Edge found, so no PNGs were made. ${INSTALL_HINT}`);
  }
  const pngLines = pngs.length > 0 ? [`✓ Saved ${pngs.length} PNGs (light and dark):`, ...pngs.map((p) => `  ${p}`)] : [];

  if (pngOnly) {
    server.stop();
    return { command: "preview", exitCode: 0, text: pngLines.join("\n"), data: { pngs } };
  }

  const pages = gallery
    ? ["/__motif/gallery"]
    : compare
      ? [`/__motif/compare?${files.map((f) => `f=${encodeURIComponent(f)}`).join("&")}`]
      : files.map(urlPath);
  const url = server.url + pages[0];
  if (flags["no-open"] !== true && !(await deps.openUrl(url))) notes.push(`Couldn't open your browser. Open ${url} yourself.`);

  const what = gallery ? "the 8 starting styles" : compare ? `${files.length} mockups side by side` : files[0];
  const lines = [
    `✓ Previewing ${what} at ${url}`,
    ...pages.slice(1).map((p) => `  Also: ${server.url}${p}`),
    gallery ? "  Press Ctrl+C to stop." : "  Pages reload when you save a mockup. Press Ctrl+C to stop.",
    ...pngLines,
    ...notes.map((n) => `• ${n}`),
  ];
  const hold = deps.waitForStop().then(() => server.stop());
  return {
    command: "preview",
    exitCode: 0,
    text: lines.join("\n"),
    data: { url, files, pngs, ...(browser ? {} : { status: "needs_browser" }) },
    hold,
  };
}
```

```ts
import { afterAll, beforeAll, describe, expect, test } from "bun:test";
import { mkdirSync, readdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { pngSize } from "../src/browser/png";

const REPO_ROOT = join(import.meta.dir, "../..");
const browser = findBrowser();
let bin = "";

describe.skipIf(!browser)("compiled motif preview (needs Chrome, Edge or Chromium)", () => {
  beforeAll(() => {
    bin = join(tempDir("motif-build-"), process.platform === "win32" ? "motif.exe" : "motif");
    const build = Bun.spawnSync([process.execPath, "build", "--compile", join(REPO_ROOT, "cli/src/main.ts"), "--outfile", bin]);
    if (build.exitCode !== 0) throw new Error(build.stderr.toString());

  const run = (args: string[]) => Bun.spawnSync([bin, ...args, "--json"], { env: { ...process.env, MOTIF_HOME: tempDir("motif-home-") } });

  test("renders the starter mockup with the project's design guide", () => {
    const root = copyFixture();
    mkdirSync(join(root, "design", "previews"), { recursive: true });
    writeFileSync(join(root, "design", "previews", "today.html"), readFileSync(join(REPO_ROOT, "skill/preview-kit/template.html"), "utf8"));

    expect(JSON.parse(r.stdout.toString()).pngs).toEqual(["design/previews/today.png", "design/previews/today.dark.png"]);
    // The phone frame is 410×864 including its bezel, at 2×.

    const pngs = readdirSync(join(root, "shots")).sort();
    expect(pngs).toHaveLength(16);
    expect(pngs).toContain("preset-dark-tech.dark.png");
  }, 180_000);
});
```
