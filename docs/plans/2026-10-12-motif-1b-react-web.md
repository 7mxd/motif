# Motif 1B — React Web Exact Half Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three new `motif` commands for React web apps — `tokens` (design guide → theme code), `check` (find values that bypass the design guide) and `extract` (draft a design guide from an app that has none).

**Architecture:** A stack-neutral `generate/` layer turns a validated `TokenDocument` into a `Theme` model and CSS-ready values; `stacks/react-web/` writes CSS variables, a Tailwind v4 theme and a typed Motion module from it; unsupported stacks get plain CSS variables plus a flat JSON file. `check/` walks the app's source files (respecting ignore rules), runs regex-based rules per file and per app, and honours `motif-ok: <reason>` exceptions. Each rule emits every literal value it sees as a `Hit` marked `violation: true|false`, so `extract/` reuses the same scanners to count values, cluster colours and infer roles into a draft contract.

**Tech Stack:** Bun 1.4, TypeScript 7, `culori` (colour parsing, OKLab distance, contrast), `jsonc-parser`, `ignore` (gitignore-style matching, new dependency).

**Spec:** `docs/specs/2026-10-12-motif-core-design.md` — implements §6.5 (rules 1, 3, 4), §6.6 (`srcDir`), §10.2 `tokens` / `check` / `extract`, §11.3, §11.5 (static rules; the runtime `shot --audit` part is Plan 1C), §12 rows "Stack outside the eight" and "Code drifted from contract".

**Deliberate differences from the spec:**
- §11.3 places the Tailwind `@theme` block inside `motif.css`. This plan writes it to a separate `motif.tailwind.css` (which imports `motif.css`), so projects and tools that don't run Tailwind never see the unknown `@theme` at-rule.
- §10.2's `motif tokens --stack preview` moves to Plan 1C, next to the preview kit that uses it.

**Builds on:** Plan 1A (merged at `12d7cf5`, then fixes up to the current `main`). Read `cli/src/contract/*`, `cli/src/detect/stacks.ts`, `cli/src/main.ts` before starting.

## Global Constraints

- Exit codes: `0` success, `1` findings/violations present, `2` usage or environment error. `--json` prints one object.
- Plain language in all text output; "design guide" and "theme values" for users.
- Generated files start with exactly one header line, then a blank line:
  - CSS: `/* Generated by Motif — edit design/tokens.json instead, then run "motif tokens". */`
  - TS: `// Generated by Motif — edit design/tokens.json instead, then run "motif tokens".`
- `motif tokens` never overwrites an existing file at a generated path unless its first line is the Motif header.
- React web output (paths relative to the app; `<src>` is the app's `srcDir`):
  - `<src>/styles/motif.css` — CSS variables `--motif-<group>-<name>`; light on `:root`; dark under `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) }` and `[data-theme="dark"]`; a global `prefers-reduced-motion` rule.
  - `<src>/styles/motif.tailwind.css` — only for Tailwind v4 projects: `@import "./motif.css";` then `@theme inline { … }`.
  - `<src>/design/motion.ts` — `duration` (seconds), `easing` (`[n, n, n, n]` tuples, not `readonly`), `spring` (`{ type: "spring", visualDuration, bounce }`).
- `srcDir`: `src` if `<app>/src` exists, else `app` if `<app>/app` exists, else `src`. Recorded per app in `design/motif.json`.
- Typography variables: `--motif-font-<role>-family|size|weight|line-height` (+ `-letter-spacing` when set).
- Tailwind v4 theme: reset `--color-*`, `--radius-*`, `--shadow-*`, `--text-*`, `--font-*`, `--ease-*` with `initial`; spacing via the single `--spacing` base (= `space.1`); font sizes via `--text-<role>` plus `--line-height`, `--font-weight`, `--letter-spacing` companions; families via `--font-<role>`.
- Check rule ids: `raw-color`, `tailwind-arbitrary`, `tailwind-palette`, `off-scale`, `raw-font`, `raw-motion`, `primitive-use`, `reduced-motion` (errors), `generated-edited` (warning).
- Exceptions: a `motif-ok: <reason>` comment on the same line or the line above turns a violation into a reported exception; a reason is required.
- `check` and `extract` skip: `node_modules`, `.git`, `dist`, `build`, `out`, `.next`, `coverage`, test files (`*.test.*`, `*.spec.*`, `__tests__/`), stories (`*.stories.*`), config files (`*.config.*`), minified files (`*.min.*`), files over 512 KB, plus `.gitignore` (root and app) and `design/motif.json` `ignore` patterns. Generated files are skipped by value rules but still count for `reduced-motion`.
- Only the React web adapter exists in Part 1; other stacks get the fallback (`tokens`) or a plain "not supported yet" message (`check`, `extract`, exit 2).
- No telemetry; nothing is uploaded.

## Review Focus

1. **Huge or minified files inside the app** (a committed 2 MB `vendor.js`, `*.min.css`) → skipped quickly, no false findings. Pinned in Task 7.
2. **Windows line endings in scanned files** → line and column numbers stay correct. Pinned in Task 8.
3. **Class names built at runtime** (`` `bg-${tone}-500` ``, `clsx({ "p-4": x })`) → no crash, no invented findings for partial class names. Pinned in Task 10.
4. **An existing file at a generated path that Motif didn't write** (a project that already has `src/styles/motif.css`) → never overwritten; a plain message explains why. Pinned in Task 6.
5. **Custom roles beyond the required ones** (`color.brand-glow`, `space.18`) → generated like any other role, and treated as on-scale by `check`. Pinned in Tasks 4 and 11.

```ts
export const SETTINGS_PATH = "design/motif.json";

export interface AppSetting {
  path: string;
  stack: string;
  srcDir?: string;
}

export interface MotifSettings {
  motifContract: 1;
  apps: AppSetting[];
  ignore: string[];
}

/** The parsed design/motif.json, or null when it's missing or not valid JSON (detectApps reports problems). */
export function readSettingsJson(root: string): unknown | null {
  try {
    return JSON.parse(stripBom(readFileSync(join(root, "design", "motif.json"), "utf8")));
  } catch {
    return null;
  }
}

export function readIgnorePatterns(root: string): string[] {
  const settings = readSettingsJson(root) as { ignore?: unknown } | null;
  return Array.isArray(settings?.ignore) ? settings.ignore.filter((p): p is string => typeof p === "string") : [];
}

export function writeSettings(root: string, settings: MotifSettings): void {
  mkdirSync(join(root, "design"), { recursive: true });
  writeFileSync(join(root, "design", "motif.json"), JSON.stringify(settings, null, 2) + "\n");
}
```

```ts
import { statSync } from "node:fs";
import { resolve } from "node:path";
import { parseArgs } from "node:util";
import { emit, type CommandResult, type RunContext } from "./cli/output";
import { runDoctor } from "./commands/doctor";
import { runValidate } from "./commands/validate";
import { VERSION } from "./version";

const HELP = `Motif ${VERSION} — design guide tools for coding agents

Usage: motif <command> [options]

Commands:
  doctor     Explain what works on this computer and what's optional
  validate   Check your design guide (DESIGN.md + design/tokens.json)

Options:
  --json     Print one JSON object (for agents and CI)
  --cwd      Run in another folder (default: the current folder)
  --app      Only this app (its path in design/motif.json)
  --version  Print the version
`;

type Runner = (cwd: string, ctx: RunContext) => Promise<CommandResult>;

const COMMANDS: Record<string, Runner> = {
  doctor: (cwd) => runDoctor(cwd),
  validate: (cwd) => runValidate(cwd),
};

export async function main(argv: string[]): Promise<number> {
  let parsed;
  try {
    parsed = parseArgs({
      args: argv,
      allowPositionals: true,
      strict: true,
      options: {
        json: { type: "boolean", default: false },
        cwd: { type: "string" },
        app: { type: "string" },
        version: { type: "boolean", default: false },
        help: { type: "boolean", short: "h", default: false },
      },
    });
  } catch (e) {
    process.stderr.write(`${(e as Error).message}\n\n${HELP}`);
    return 2;
  }
  const { values, positionals } = parsed;
  if (values.version) {
    process.stdout.write(`${VERSION}\n`);
    return 0;
  }
  const command = positionals[0];
  if (values.help || command === "help") {
    process.stdout.write(HELP);
    return 0;
  }
  if (!command) {
    process.stdout.write(HELP);
    return 2;
  }
  if (!Object.hasOwn(COMMANDS, command)) {
    process.stderr.write(`Unknown command "${command}".\n\n${HELP}`);
    return 2;
  }
  const runner = COMMANDS[command]!;
  const json = values.json ?? false;
  const cwd = resolve(values.cwd ?? process.cwd());
  if (!isFolder(cwd)) {
    emit({ command, exitCode: 2, text: `This folder doesn't exist: ${cwd}`, data: { error: "no-folder", folder: cwd } }, json);
    return 2;
  }
  let result: CommandResult;
  try {
    result = await runner(cwd, { positionals: positionals.slice(1), app: values.app });
  } catch (e) {
    const message = e instanceof Error ? e.message : String(e);
    result = {
      command,
      exitCode: 2,
      text: `Motif hit an unexpected problem and stopped: ${message}\nPlease report this at https://github.com/7mxd/motif/issues`,
      data: { error: "unexpected", message },
    };
  }
  emit(result, json);
  return result.exitCode;
}

function isFolder(path: string): boolean {
  try {
    return statSync(path).isDirectory();
  } catch {
    return false;
  }
}

if (import.meta.main) process.exit(await main(process.argv.slice(2)));
```

```ts
import { durationToMs, type DtcgColor, type DtcgDuration } from "../contract/values";

export interface DtcgDimension {
  value: number;
  unit: "px" | "rem";
}

export function num(n: number): string {
  return String(Number.parseFloat(n.toFixed(4)));
}

const channel = (c: number | "none") => (c === "none" ? "none" : num(c));
const percent = (c: number | "none") => (c === "none" ? "none" : `${num(c)}%`);

export function cssColor(c: DtcgColor): string {
  const alpha = c.alpha !== undefined && c.alpha < 1 ? ` / ${num(c.alpha)}` : "";
  const [a, b, d] = c.components as [number | "none", number | "none", number | "none"];
  switch (c.colorSpace) {
    case "srgb": {
      if (!alpha && c.hex) return c.hex.toUpperCase();
      const to255 = (x: number | "none") => (x === "none" ? 0 : Math.round(x * 255));
      return `rgb(${to255(a)} ${to255(b)} ${to255(d)}${alpha})`;
    }
    case "hsl":
    case "hwb":
      return `${c.colorSpace}(${channel(a)} ${percent(b)} ${percent(d)}${alpha})`;
    case "lab":
    case "lch":
    case "oklab":
    case "oklch":
      return `${c.colorSpace}(${channel(a)} ${channel(b)} ${channel(d)}${alpha})`;
    default:
      return `color(${c.colorSpace} ${channel(a)} ${channel(b)} ${channel(d)}${alpha})`;
  }
}

export function cssDimension(d: DtcgDimension): string {
  return `${num(d.value)}${d.unit}`;
}

export function dimensionPx(d: DtcgDimension): number {
  return d.unit === "rem" ? d.value * 16 : d.value;
}

export function cssDuration(d: DtcgDuration): string {
  return `${num(durationToMs(d))}ms`;
}

export function cssCubicBezier(p: number[]): string {
  return `cubic-bezier(${p.map(num).join(", ")})`;
}

interface ShadowLayer {
  color: DtcgColor;
  offsetX: DtcgDimension;
  offsetY: DtcgDimension;
  blur: DtcgDimension;
  spread: DtcgDimension;
  inset?: boolean;
}

export function cssShadow(v: unknown): string {
  const layers = (Array.isArray(v) ? v : [v]) as ShadowLayer[];
  return layers
    .map((l) => `${l.inset ? "inset " : ""}${cssDimension(l.offsetX)} ${cssDimension(l.offsetY)} ${cssDimension(l.blur)} ${cssDimension(l.spread)} ${cssColor(l.color)}`)
    .join(", ");
}

const GENERIC_FAMILIES = new Set([
  "serif", "sans-serif", "monospace", "cursive", "fantasy", "system-ui", "ui-serif", "ui-sans-serif",
  "ui-monospace", "ui-rounded", "math", "emoji", "fangsong",
]);

export function cssFontFamily(v: string | string[]): string {
  return (Array.isArray(v) ? v : [v])
    .map((name) => (GENERIC_FAMILIES.has(name.toLowerCase()) || /^[A-Za-z][\w-]*$/.test(name) ? name : `"${name.replace(/"/g, '\\"')}"`))
    .join(", ");
}

const WEIGHTS: Record<string, number> = {
  thin: 100, hairline: 100, "extra-light": 200, "ultra-light": 200, light: 300, normal: 400, regular: 400, book: 400,
  medium: 500, "semi-bold": 600, "demi-bold": 600, bold: 700, "extra-bold": 800, "ultra-bold": 800,
  black: 900, heavy: 900, "extra-black": 950, "ultra-black": 950,
};

export function fontWeightNumber(v: number | string): number {
  return typeof v === "number" ? v : (WEIGHTS[v] ?? 400);
}
```

```ts
import { resolveMode, resolveToken } from "../contract/resolve";
import type { TokenDocument } from "../contract/types";
import { durationToMs, validateValue, type DtcgColor, type DtcgDuration } from "../contract/values";
import { cssDimension, cssFontFamily, cssShadow, dimensionPx, fontWeightNumber, type DtcgDimension } from "./css-values";

export interface ThemeColor {
  name: string;
  light: DtcgColor;
  dark: DtcgColor;
}

export interface ThemeSize {
  name: string;
  px: number;
  css: string;
}

export interface ThemeFont {
  name: string;
  family: string;
  sizeCss: string;
  sizePx: number;
  weight: number;
  lineHeight: number;
  letterSpacing?: string;
}

export interface Theme {
  colors: ThemeColor[];
  space: ThemeSize[];
  radius: ThemeSize[];
  shadows: { name: string; css: string }[];
  fonts: ThemeFont[];
  durations: { name: string; ms: number }[];
  easings: { name: string; points: [number, number, number, number] }[];
  springs: { name: string; duration: number; bounce: number }[];
}

interface Typography {
  fontFamily: string | string[];
  fontSize: DtcgDimension;
  fontWeight: number | string;
  lineHeight: number;
  letterSpacing?: DtcgDimension;
}

export function buildTheme(doc: TokenDocument): Theme {
  const theme: Theme = { colors: [], space: [], radius: [], shadows: [], fonts: [], durations: [], easings: [], springs: [] };
  const springs = new Map<string, { duration?: number; bounce?: number }>();

  for (const tok of doc.tokens.values()) {
    const [group, ...rest] = tok.path.split(".");
    if (!group || group === "primitive" || rest.length === 0) continue;
    const r = resolveToken(doc, tok.path);
    if (!r.ok || r.type === null || validateValue(r.type, r.value) !== null) continue;

    if (group === "spring") {
      if (rest.length < 2) continue;
      const name = rest.slice(0, -1).join("-");
      const field = rest[rest.length - 1];
      const s = springs.get(name) ?? {};
      if (field === "duration" && r.type === "duration") s.duration = durationToMs(r.value as DtcgDuration) / 1000;
      if (field === "bounce" && r.type === "number") s.bounce = r.value as number;
      springs.set(name, s);
      continue;
    }

    const name = rest.join("-");
    switch (`${group}:${r.type}`) {
      case "color:color": {
        const dark = resolveMode(doc, tok.path, "dark");
        const darkOk = dark.ok && validateValue("color", dark.value) === null;
        theme.colors.push({ name, light: r.value as DtcgColor, dark: (darkOk ? dark.value : r.value) as DtcgColor });
        break;
      }
      case "space:dimension":
      case "radius:dimension": {
        const d = r.value as DtcgDimension;
        (group === "space" ? theme.space : theme.radius).push({ name, px: dimensionPx(d), css: cssDimension(d) });
        break;
      }
      case "shadow:shadow":
        theme.shadows.push({ name, css: cssShadow(r.value) });
        break;
      case "font:typography": {
        const t = r.value as Typography;
        theme.fonts.push({
          name,
          family: cssFontFamily(t.fontFamily),
          sizeCss: cssDimension(t.fontSize),
          sizePx: dimensionPx(t.fontSize),
          weight: fontWeightNumber(t.fontWeight),
          lineHeight: t.lineHeight,
          ...(t.letterSpacing ? { letterSpacing: cssDimension(t.letterSpacing) } : {}),
        });
        break;
      }
      case "duration:duration":
        theme.durations.push({ name, ms: durationToMs(r.value as DtcgDuration) });
        break;
      case "easing:cubicBezier":
        theme.easings.push({ name, points: [...(r.value as number[])] as [number, number, number, number] });
        break;
    }
  }

  for (const [name, s] of springs) {
    if (s.duration !== undefined && s.bounce !== undefined) theme.springs.push({ name, duration: s.duration, bounce: s.bounce });
  }
  return theme;
}
```

```ts
export const CSS_HEADER = '/* Generated by Motif — edit design/tokens.json instead, then run "motif tokens". */';
export const TS_HEADER = '// Generated by Motif — edit design/tokens.json instead, then run "motif tokens".';
export const JSON_COMMENT = 'Generated by Motif — edit design/tokens.json instead, then run "motif tokens".';

export interface GeneratedFile {
  /** Relative path with forward slashes. */
  path: string;
  content: string;
}

/** True only for files Motif wrote: they start with Motif's header (or carry its $comment, for JSON). */
export function isMotifGenerated(path: string, text: string): boolean {
  const t = stripBom(text);
  if (path.endsWith(".json")) {
    try {
      return JSON.parse(t)?.$comment === JSON_COMMENT;
    } catch {
      return false;
    }
  }
  const first = t.split(/\r?\n/, 1)[0];
  return first === CSS_HEADER || first === TS_HEADER;
}

const normalize = (s: string) => stripBom(s).replace(/\r\n/g, "\n");

export function sameContent(a: string, b: string): boolean {
  return normalize(a) === normalize(b);
}
```

```ts
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { cssColor, cssCubicBezier, num } from "../../generate/css-values";
import { CSS_HEADER, TS_HEADER, type GeneratedFile } from "../../generate/header";
import type { Theme } from "../../generate/theme";
import { stripBom } from "../../text";

export type TailwindVersion = "v4" | "v3" | "none";

const V4_PACKAGES = ["@tailwindcss/vite", "@tailwindcss/postcss", "@tailwindcss/cli"];

export function detectTailwind(appDir: string): TailwindVersion {
  let deps: Record<string, unknown>;
  try {
    const pkg = JSON.parse(stripBom(readFileSync(join(appDir, "package.json"), "utf8")));
    deps = { ...pkg.dependencies, ...pkg.devDependencies };
  } catch {
    return "none";
  }
  if (V4_PACKAGES.some((d) => Object.hasOwn(deps, d))) return "v4";
  if (!Object.hasOwn(deps, "tailwindcss")) return "none";
  return /^[\^~>=<\s]*[0-3]\./.test(String(deps.tailwindcss)) ? "v3" : "v4";
}

export function chooseSrcDir(appDir: string): string {
  if (existsSync(join(appDir, "src"))) return "src";
  if (existsSync(join(appDir, "app"))) return "app";
  return "src";
}

const cssVar = (group: string, name: string) => `--motif-${group}-${name}`;
const indent = (lines: string[], n: number) => lines.map((l) => (l ? " ".repeat(n) + l : "")).join("\n");

function rootVariables(theme: Theme): string[] {
  const lines: string[] = [];
  for (const c of theme.colors) lines.push(`${cssVar("color", c.name)}: ${cssColor(c.light)};`);
  for (const s of theme.space) lines.push(`${cssVar("space", s.name)}: ${s.css};`);
  for (const r of theme.radius) lines.push(`${cssVar("radius", r.name)}: ${r.css};`);
  for (const s of theme.shadows) lines.push(`${cssVar("shadow", s.name)}: ${s.css};`);
  for (const f of theme.fonts) {
    const p = cssVar("font", f.name);
    lines.push(`${p}-family: ${f.family};`, `${p}-size: ${f.sizeCss};`, `${p}-weight: ${f.weight};`, `${p}-line-height: ${num(f.lineHeight)};`);
    if (f.letterSpacing) lines.push(`${p}-letter-spacing: ${f.letterSpacing};`);
  }
  for (const d of theme.durations) lines.push(`${cssVar("duration", d.name)}: ${num(d.ms)}ms;`);
  for (const e of theme.easings) lines.push(`${cssVar("easing", e.name)}: ${cssCubicBezier(e.points)};`);
  return lines;
}

const darkVariables = (theme: Theme) => theme.colors.map((c) => `${cssVar("color", c.name)}: ${cssColor(c.dark)};`);

export function motifCss(theme: Theme): string {
  return [
    CSS_HEADER,
    "",
    ":root,",
    '[data-theme="light"] {',
    indent(["color-scheme: light;", ...rootVariables(theme)], 2),
    "}",
    "",
    "@media (prefers-color-scheme: dark) {",
    '  :root:not([data-theme="light"]) {',
    indent(["color-scheme: dark;", ...darkVariables(theme)], 4),
    "  }",
    "}",
    "",
    '[data-theme="dark"] {',
    indent(["color-scheme: dark;", ...darkVariables(theme)], 2),
    "}",
    "",
    "@media (prefers-reduced-motion: reduce) {",
    "  *,",
    "  *::before,",
    "  *::after {",
    "    animation-duration: 0.01ms !important;",
    "    animation-iteration-count: 1 !important;",
    "    transition-duration: 0.01ms !important;",
    "    scroll-behavior: auto !important;",
    "  }",
    "}",
    "",
  ].join("\n");
}

export function tailwindCss(theme: Theme): string {
  const lines = [
    "--color-*: initial;",
    "--radius-*: initial;",
    "--shadow-*: initial;",
    "--text-*: initial;",
    "--font-*: initial;",
    "--ease-*: initial;",
    "",
  ];
  for (const c of theme.colors) lines.push(`--color-${c.name}: var(${cssVar("color", c.name)});`);
  if (theme.space.some((s) => s.name === "1")) lines.push(`--spacing: var(${cssVar("space", "1")});`);
  for (const r of theme.radius) lines.push(`--radius-${r.name}: var(${cssVar("radius", r.name)});`);
  for (const s of theme.shadows) lines.push(`--shadow-${s.name}: var(${cssVar("shadow", s.name)});`);
  for (const f of theme.fonts) {
    const p = cssVar("font", f.name);
    lines.push(
      `--font-${f.name}: var(${p}-family);`,
      `--text-${f.name}: var(${p}-size);`,
      `--text-${f.name}--line-height: var(${p}-line-height);`,
      `--text-${f.name}--font-weight: var(${p}-weight);`,
    );
    if (f.letterSpacing) lines.push(`--text-${f.name}--letter-spacing: var(${p}-letter-spacing);`);
  }
  if (theme.fonts.some((f) => f.name === "body")) lines.push(`--default-font-family: var(${cssVar("font", "body")}-family);`);
  for (const e of theme.easings) lines.push(`--ease-${e.name}: var(${cssVar("easing", e.name)});`);
  return [CSS_HEADER, "", '@import "./motif.css";', "", "@theme inline {", indent(lines, 2), "}", ""].join("\n");
}

const key = (name: string) => (/^[A-Za-z_$][\w$]*$/.test(name) ? name : JSON.stringify(name));

export function motionTs(theme: Theme): string {
  return [
    TS_HEADER,
    "",
    "/** Durations in seconds (the unit Motion uses). */",
    "export const duration = {",
    ...theme.durations.map((d) => `  ${key(d.name)}: ${num(d.ms / 1000)},`),
    "} satisfies Record<string, number>;",
    "",
    "export type Easing = [number, number, number, number];",
    "",
    "export const easing = {",
    ...theme.easings.map((e) => `  ${key(e.name)}: [${e.points.map(num).join(", ")}],`),
    "} satisfies Record<string, Easing>;",
    "",
    'export type Spring = { type: "spring"; visualDuration: number; bounce: number };',
    "",
    "export const spring = {",
    ...theme.springs.map((s) => `  ${key(s.name)}: { type: "spring", visualDuration: ${num(s.duration)}, bounce: ${num(s.bounce)} },`),
    "} satisfies Record<string, Spring>;",
    "",
  ].join("\n");
}

export function generateReactWeb(theme: Theme, opts: { srcDir: string; tailwind: TailwindVersion }): GeneratedFile[] {
  const files: GeneratedFile[] = [{ path: `${opts.srcDir}/styles/motif.css`, content: motifCss(theme) }];
```

```ts
export type FileStatus = "created" | "updated" | "unchanged" | "protected";

export function writeGenerated(root: string, files: GeneratedFile[]): { path: string; status: FileStatus }[] {
  return files.map((f) => {
    const abs = join(root, f.path);
    if (existsSync(abs)) {
      const current = readFileSync(abs, "utf8");
      if (!isMotifGenerated(f.path, current)) return { path: f.path, status: "protected" as const };
      if (sameContent(current, f.content)) return { path: f.path, status: "unchanged" as const };
      writeFileSync(abs, f.content);
      return { path: f.path, status: "updated" as const };
    }
    mkdirSync(dirname(abs), { recursive: true });
    writeFileSync(abs, f.content);
    return { path: f.path, status: "created" as const };
  });
}

/** Create design/motif.json from detection, or add missing srcDir values. Returns null when left alone. */
function updateSettings(root: string, detected: AppInfo[], srcDirs: Map<string, string>, notes: string[]): FileStatus | null {
  const exists = existsSync(join(root, "design", "motif.json"));
  const raw = readSettingsJson(root) as { apps?: unknown; ignore?: unknown } | null;
  if (exists && (raw === null || !Array.isArray(raw.apps))) {
    notes.push("design/motif.json couldn't be read, so Motif didn't update it.");
    return null;
  }
  if (!exists) {
    const apps: AppSetting[] = detected
      .filter((a) => a.stack !== null)
      .map((a) => ({ path: a.path, stack: a.stack!, ...(srcDirs.has(a.path) ? { srcDir: srcDirs.get(a.path)! } : {}) }));
    writeSettings(root, { motifContract: 1, apps, ignore: [] });
    return "created";
  }
  let changed = false;
  const apps = (raw!.apps as AppSetting[]).map((a) => {
    if (a?.stack === "react-web" && typeof a.srcDir !== "string" && srcDirs.has(a.path)) {
      changed = true;
      return { ...a, srcDir: srcDirs.get(a.path)! };
    }
    return a;
  });
  if (!changed) return "unchanged";
  const ignore = Array.isArray(raw!.ignore) ? (raw!.ignore as string[]) : [];
  writeSettings(root, { motifContract: 1, apps, ignore });
  return "updated";
}

const CODE_FILE = /\.(css|scss|ts|tsx|js|jsx|mjs)$/;

/** True when any file under dir (other than Motif's own) mentions name. Bounded to 2000 files. */
function isReferenced(dir: string, name: string): boolean {
  let seen = 0;
  const visit = (d: string): boolean => {
    let entries: string[];
    try {
      entries = readdirSync(d);
    } catch {
      return false;
    }
    for (const e of entries) {
      if (e === "node_modules" || e.startsWith(".") || seen++ > 2000) continue;
      const p = join(d, e);
      let isDir = false;
      try {
        isDir = statSync(p).isDirectory();
      } catch {
        continue;
      }
      if (isDir) {
        if (visit(p)) return true;
      } else if (CODE_FILE.test(e)) {
        const text = readFileSync(p, "utf8");
        if (text.includes(name) && !isMotifGenerated(e, text)) return true;
      }
    }
    return false;
  };
  return visit(dir);
}

export async function runTokens(cwd: string, ctx: RunContext): Promise<CommandResult> {
  const tokensPath = join(cwd, "design", "tokens.json");
  if (!existsSync(tokensPath)) {
    return {
      command: "tokens",
      exitCode: 2,
      text: "No design guide found in this folder (missing design/tokens.json).\nStart one with /design, or draft one from your app with motif extract.",
      data: { error: "no-contract" },
    };
  }

  const { doc, findings: loadFindings } = loadTokenDocument(TOKENS_JSON, readFileSync(tokensPath, "utf8"));
  const problems: Finding[] = doc
    ? [...loadFindings, ...validateTokens(doc), ...checkRoles(doc)].filter((f) => f.severity === "error")
    : loadFindings;
  if (!doc || problems.length > 0) {
    return {
      command: "tokens",
      exitCode: 1,
      text: `✗ Your theme values have ${problems.length} ${problems.length === 1 ? "problem" : "problems"}, so no code was generated:\n${formatFindings(problems)}\nFix these first (motif validate shows details).`,
      data: { error: "invalid-contract", findings: problems },
    };
  }

  const detected = detectApps(cwd).apps;
  const apps = selectApps(detected, ctx.app);
  if (apps === null) {
    return {
      command: "tokens",
      exitCode: 2,
      text: `There's no app at "${ctx.app}". Apps here: ${detected.map((a) => a.path).join(", ") || "none"}.`,
      data: { error: "no-such-app" },
    };
  }
  if (apps.length === 0) {
    return { command: "tokens", exitCode: 2, text: "No app found in this folder. Start one with /design first.", data: { error: "no-app" } };
  }

  const theme = buildTheme(doc);
  const files: GeneratedFile[] = [];
  const notes: string[] = [];
  const srcDirs = new Map<string, string>();
  const entries: { dir: string; entry: string; label: string }[] = [];
  let needsFallback = false;

  for (const app of apps) {
    const appDir = join(cwd, app.path);
    if (app.stack === "react-web") {
      const srcDir = app.srcDir ?? chooseSrcDir(appDir);
      const tailwind = detectTailwind(appDir);
      srcDirs.set(app.path, srcDir);
      if (tailwind === "v3") {
        notes.push(`${appLabel(app)}: Tailwind v3 found, so Motif wrote CSS variables only. Use them as bg-[var(--motif-color-action-primary)], or upgrade to Tailwind v4 for Motif's Tailwind theme.`);

    } else {
      notes.push(`${appLabel(app)}: Motif couldn't tell which framework this app uses, so it was skipped. Add it to design/motif.json.`);
    }

  if (needsFallback) files.push(...generateFallback(theme));

  const results = writeGenerated(cwd, files);
  const settingsStatus = updateSettings(cwd, detected, srcDirs, notes);
  if (settingsStatus) results.push({ path: "design/motif.json", status: settingsStatus });

  for (const e of entries) {
    if (!isReferenced(e.dir, e.entry)) notes.push(`Next: import "./styles/${e.entry}" once in ${e.label === "Your app" ? "your app" : e.label}'s main CSS file.`);
  }

  const blocked = results.filter((r) => r.status === "protected");
  const allSame = results.every((r) => r.status === "unchanged");
  const lines = [
    blocked.length > 0 ? "✗ Some theme files couldn't be written:" : allSame ? "✓ Theme code is up to date." : "✓ Theme code is ready:",

    command: "tokens",
```

```ts
import { readdirSync, readFileSync, statSync } from "node:fs";
import { extname, join } from "node:path";
import ignore from "ignore";
import { stripBom } from "../text";

export type Lang = "css" | "script" | "markup";

export interface SourceFile {
  /** Relative to the project root, forward slashes. */
  path: string;
  abs: string;
  text: string;
  lang: Lang;
}

const LANGS: Record<string, Lang> = {
  ".css": "css", ".scss": "css", ".sass": "css", ".less": "css",
  ".ts": "script", ".tsx": "script", ".js": "script", ".jsx": "script", ".mjs": "script", ".cjs": "script",
  ".html": "markup", ".mdx": "markup",
};

export const DEFAULT_IGNORES = [
  "node_modules/", ".git/", "dist/", "build/", "out/", ".next/", "coverage/", "__tests__/",
  "*.test.*", "*.spec.*", "*.stories.*", "*.config.*", "*.min.*", "*.d.ts",
];

export const MAX_FILE_BYTES = 512 * 1024;
const MAX_LINE_LENGTH = 3000;

function readGitignore(dir: string): string[] {
  try {
    return stripBom(readFileSync(join(dir, ".gitignore"), "utf8")).split(/\r?\n/);
  } catch {
    return [];
  }
}

const toPosix = (p: string) => p.replace(/\\/g, "/").replace(/^\.\//, "").replace(/\/+$/, "");

export function listSourceFiles(root: string, appPath: string, opts: { paths?: string[]; ignore?: string[] } = {}): SourceFile[] {
  const rootIgnore = ignore().add(DEFAULT_IGNORES).add(readGitignore(root)).add(opts.ignore ?? []);
  const app = toPosix(appPath) || ".";
  const appDir = join(root, app);
  const appIgnore = app === "." ? null : ignore().add(readGitignore(appDir));
  const wanted = (opts.paths ?? []).map(toPosix).filter(Boolean);
  const dirWanted = (rel: string) => wanted.length === 0 || wanted.some((w) => w === rel || w.startsWith(rel + "/") || rel.startsWith(w + "/"));
  const fileWanted = (rel: string) => wanted.length === 0 || wanted.some((w) => rel === w || rel.startsWith(w + "/"));
  const appRelative = (rel: string) => (app === "." ? rel : rel.slice(app.length + 1));

  const out: SourceFile[] = [];
  const visit = (absDir: string, rel: string) => {
    let entries: string[];
    try {
      entries = readdirSync(absDir).sort();
    } catch {
      return;
    }
    for (const name of entries) {
      const abs = join(absDir, name);
      const relPath = rel ? `${rel}/${name}` : name;
      let st;
      try {
        st = statSync(abs);
      } catch {
        continue;
      }
      if (st.isDirectory()) {
        if (rootIgnore.ignores(relPath + "/") || appIgnore?.ignores(appRelative(relPath) + "/")) continue;
        if (dirWanted(relPath)) visit(abs, relPath);
        continue;
      }
      const lang = LANGS[extname(name).toLowerCase()];
      if (!lang || st.size > MAX_FILE_BYTES) continue;
      if (rootIgnore.ignores(relPath) || appIgnore?.ignores(appRelative(relPath))) continue;
      if (!fileWanted(relPath)) continue;
      const text = stripBom(readFileSync(abs, "utf8"));
      if (text.split("\n").some((line) => line.length > MAX_LINE_LENGTH)) continue;
      out.push({ path: relPath, abs, text, lang });
    }
  };
  visit(appDir, app === "." ? "" : app);
  return out;
}
```

```ts
/** Maps a character index to a 1-based line and column. A CR before LF stays on its line, so CRLF files work. */
export function locator(text: string): (index: number) => { line: number; column: number } {
  const starts = [0];
  for (let i = 0; i < text.length; i++) if (text.charCodeAt(i) === 10) starts.push(i + 1);
  return (index) => {
    let lo = 0;
    let hi = starts.length - 1;
    while (lo < hi) {
      const mid = (lo + hi + 1) >> 1;
      if (starts[mid]! <= index) lo = mid;
      else hi = mid - 1;
    }
    return { line: lo + 1, column: index - starts[lo]! + 1 };
  };
}
```

```ts
const MOTIF_OK = /motif-ok\b(?:\s*:\s*(.*?))?\s*(?:\*\/|\}|-->|$)/;

export type ExceptionResult = { reason: string } | { missingReason: true } | null;

/** A `motif-ok: <reason>` comment on the given 1-based line or the line above it. */
export function exceptionFor(lines: string[], line: number): ExceptionResult {
  for (const text of [lines[line - 1], lines[line - 2]]) {
    if (text === undefined) continue;
    const m = text.match(MOTIF_OK);
    if (!m) continue;
    const reason = (m[1] ?? "").trim();
    return reason ? { reason } : { missingReason: true };
  }
  return null;
}
```

```ts
      text: literal,
      value: literal,
      kind: "color",
      context,
      violation: true,
      message: `Raw colour ${literal}.`,
      fix: "Use a theme colour instead: a class like bg-action-primary or text-text-primary, or var(--motif-color-<role>).",
    }));

    }
    return hits.sort((a, b) => a.line - b.line || a.column - b.column);

    const lineStart = file.text.lastIndexOf("\n", index - 1) + 1;
    const key = file.text.slice(lineStart, index).match(KEY_BEFORE)?.[1];
    return key ? colorContext(key) : "other";
```

```ts
import { locator } from "../../text";
import type { SourceFile } from "../files";
import { makeHit, type Hit, type RuleId, type Scale, type ValueKind } from "../types";
import { NAMED_COLORS } from "./colors";

/** Class boundary, optional variants (hover:, md:, dark:…), optional ! and a negative sign. */
export const CLASS_PREFIX = "(?<![\\w-])(?:[\\w-]+:)*!?-?";

const ARBITRARY = new RegExp(`${CLASS_PREFIX}([a-z]+(?:-[a-z]+)*)-\\[([^\\]\\s]+)\\]`, "g");
const TW_COLORS = "slate|gray|zinc|neutral|stone|red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose";
const PALETTE = new RegExp(
  `${CLASS_PREFIX}(bg|text|border(?:-[xytrblse])?|ring(?:-offset)?|outline|fill|stroke|decoration|caret|accent|from|via|to|divide|placeholder|shadow)-(?:(${TW_COLORS})-(50|[1-9]00|950)|(black|white))(?:\\/\\d{1,3})?(?![\\w-])`,
  "g",
);

const COLOR_UTILS = new Set([
  "bg", "border", "border-x", "border-y", "border-t", "border-r", "border-b", "border-l", "border-s", "border-e",
  "ring", "ring-offset", "outline", "fill", "stroke", "decoration", "caret", "accent", "from", "via", "to", "divide", "placeholder",
]);
const SPACE_UTILS = new Set([
  "p", "px", "py", "pt", "pr", "pb", "pl", "ps", "pe", "m", "mx", "my", "mt", "mr", "mb", "ml", "ms", "me",
  "gap", "gap-x", "gap-y", "space-x", "space-y", "inset", "inset-x", "inset-y", "top", "right", "bottom", "left", "start", "end",
]);
const RADIUS_UTIL = /^rounded(?:-(?:t|r|b|l|s|e|tl|tr|br|bl|ss|se|es|ee))?$/;

const isColorLiteral = (v: string) =>
  /^#[0-9a-fA-F]{3,8}$/.test(v) || /^(?:rgba?|hsla?|hwb|oklab|oklch|lab|lch|color)\(/.test(v) || NAMED_COLORS.has(v.toLowerCase());
const isLength = (v: string) => /^-?\d*\.?\d+(?:px|rem|em)$/.test(v);
const isMotifVar = (v: string) => /^(?:var\()?--motif-/.test(v);

export function toPx(length: string): number {
  const n = Number.parseFloat(length);
  return /px$/.test(length) ? n : n * 16;
}

export function utilContext(util: string): "text" | "background" | "border" | "other" {
  if (util === "bg" || util === "from" || util === "via" || util === "to") return "background";
  if (["text", "fill", "stroke", "decoration", "caret", "placeholder", "accent"].includes(util)) return "text";
  if (util.startsWith("border") || util.startsWith("ring") || util === "outline" || util === "divide") return "border";
  return "other";
}

export function classSegments(file: SourceFile): { text: string; offset: number }[] {
  if (file.lang !== "css") return [{ text: file.text, offset: 0 }];
  return [...file.text.matchAll(/@apply\s+([^;]+);/g)].map((m) => ({ text: m[1]!, offset: m.index! + m[0].indexOf(m[1]!) }));
}

interface Classified {
  rule: RuleId;
  kind: ValueKind;
  value: string;
  context?: string;
  message: string;
  fix: string;
}

function classifyArbitrary(util: string, value: string, cls: string, motionImport: string): Classified | null {
  if (isMotifVar(value)) return null;
  if (util === "duration" || util === "delay") {
    return { rule: "raw-motion", kind: "duration", value, message: `Hard-coded animation timing ${cls}.`, fix: `Use duration-(--motif-duration-base) (or fast/slow), or import { duration } from "${motionImport}".` };
  }
  if (util === "ease") {
    return { rule: "raw-motion", kind: "easing", value, message: `Hard-coded easing ${cls}.`, fix: "Use ease-standard, ease-enter or ease-exit." };
  }
  if (util === "font") {
    if (/^\d+$/.test(value)) return null;
    return { rule: "raw-font", kind: "font-family", value, message: `Hard-coded font ${cls}.`, fix: "Use a font role class such as font-body." };
  }
  const color = (context: string): Classified => ({
    rule: "tailwind-arbitrary", kind: "color", value, context, message: `Arbitrary colour ${cls}.`, fix: "Use a theme colour class such as bg-action-primary or text-text-primary.",
  });
  if (util === "text") {
    if (isColorLiteral(value)) return color("text");
    if (isLength(value)) return { rule: "tailwind-arbitrary", kind: "font-size", value: `${toPx(value)}px`, message: `Arbitrary text size ${cls}.`, fix: "Use a text role class such as text-body or text-heading." };
    return null;
  }
  if (util === "shadow") {
    if (isColorLiteral(value)) return color("other");
    return { rule: "tailwind-arbitrary", kind: "shadow", value, message: `Arbitrary shadow ${cls}.`, fix: "Use shadow-sm, shadow-md or shadow-lg." };
  }
  if (COLOR_UTILS.has(util) && isColorLiteral(value)) return color(utilContext(util));
  if (SPACE_UTILS.has(util) && isLength(value)) {
    return { rule: "tailwind-arbitrary", kind: "space", value: `${toPx(value)}px`, message: `Arbitrary spacing ${cls}.`, fix: "Use a step from your spacing scale, e.g. p-4." };
  }
  if (RADIUS_UTIL.test(util) && isLength(value)) {
    return { rule: "tailwind-arbitrary", kind: "radius", value: `${toPx(value)}px`, message: `Arbitrary corner size ${cls}.`, fix: "Use rounded-sm, rounded-md, rounded-lg or rounded-full." };
  }
  return null;
}

export function scanTailwind(file: SourceFile, scale: Scale | null): Hit[] {
  const at = locator(file.text);
  const motionImport = scale?.motionImport ?? "design/motion";
  const hits: Hit[] = [];
  for (const seg of classSegments(file)) {
    for (const m of seg.text.matchAll(ARBITRARY)) {
      const c = classifyArbitrary(m[1]!, m[2]!, m[0], motionImport);
      if (c) hits.push(makeHit(file, at, seg.offset + m.index!, { ...c, text: m[0], violation: true }));
    }
    for (const m of seg.text.matchAll(PALETTE)) {
      const value = m[2] ? `${m[2]}-${m[3]}` : m[4]!;
      hits.push(makeHit(file, at, seg.offset + m.index!, {
        rule: "tailwind-palette",
        kind: "color",
        value,
        context: utilContext(m[1]!),
        text: m[0],
        violation: true,
        message: `Tailwind default colour ${m[0]} — Motif's theme replaces the default palette.`,
        fix: "Use a theme colour class such as bg-action-primary or text-text-secondary.",
      }));
    }
  }
  return hits.sort((a, b) => a.line - b.line || a.column - b.column);
}
```

```ts
import { CLASS_PREFIX, classSegments } from "./tailwind";

/** Tailwind v4's default --spacing (0.25rem), used to read spacing classes in apps without Motif's theme yet. */
export const TAILWIND_SPACING_PX = 4;

const SPACING = new RegExp(`${CLASS_PREFIX}(p[xytrblse]?|m[xytrblse]?|gap(?:-[xy])?|space-[xy]|inset(?:-[xy])?|top|right|bottom|left|start|end)-(\\d+(?:\\.\\d+)?|px)(?![\\w.-])`, "g");
const RADIUS = new RegExp(`${CLASS_PREFIX}rounded(?:-(?:t|r|b|l|s|e|tl|tr|br|bl|ss|se|es|ee))?-(xs|sm|md|lg|xl|2xl|3xl|4xl|none|full)(?![\\w-])`, "g");
const TEXT_SIZE = new RegExp(`${CLASS_PREFIX}text-(xs|sm|base|lg|xl|[2-9]xl)(?![\\w-])`, "g");
const SHADOW = new RegExp(`${CLASS_PREFIX}shadow-(2xs|xs|sm|md|lg|xl|2xl|inner)(?![\\w-])`, "g");
const TIMING = new RegExp(`${CLASS_PREFIX}(duration|delay)-(\\d+)(?![\\w-])`, "g");
const EASE = new RegExp(`${CLASS_PREFIX}ease-(linear|in|out|in-out)(?![\\w-])`, "g");
const FONT = new RegExp(`${CLASS_PREFIX}font-(sans|serif|mono)(?![\\w-])`, "g");

const list = (prefix: string, keys: Set<string> | undefined) => [...(keys ?? [])].map((k) => `${prefix}${k}`).join(", ");

export function scanTailwindScale(file: SourceFile, scale: Scale | null): Hit[] {
  const at = locator(file.text);
  const hits: Hit[] = [];
  const push = (index: number, cls: string, rule: RuleId, kind: ValueKind, value: string, violation: boolean, message: string, fix: string) =>
    hits.push(makeHit(file, at, index, { rule, kind, value, text: cls, violation, message, fix }));
  const offScale = (keys: Set<string> | undefined, key: string) => (scale ? !keys!.has(key) : false);
  const motionImport = scale?.motionImport ?? "design/motion";

  for (const seg of classSegments(file)) {
    const base = seg.offset;
    for (const m of seg.text.matchAll(SPACING)) {
      const key = m[2]!;
      const px = key === "px" ? 1 : Number(key) * TAILWIND_SPACING_PX;
      const violation = scale ? key === "px" || !scale.spaceKeys.has(key) : false;
      push(base + m.index!, m[0], "off-scale", "space", `${px}px`, violation, `Spacing ${m[0]} isn't on your spacing scale.`, `Use a step from your scale: ${list("", scale?.spaceKeys)} (e.g. p-4).`);
    }
    for (const m of seg.text.matchAll(RADIUS)) {
      push(base + m.index!, m[0], "off-scale", "radius", m[1]!, offScale(scale?.radiusKeys, m[1]!), `Corner size ${m[0]} isn't one of your radius roles.`, `Use ${list("rounded-", scale?.radiusKeys)}.`);
    }
    for (const m of seg.text.matchAll(TEXT_SIZE)) {
      push(base + m.index!, m[0], "off-scale", "font-size", m[1]!, offScale(scale?.textKeys, m[1]!), `Text size ${m[0]} isn't one of your text roles.`, `Use ${list("text-", scale?.textKeys)}.`);
    }
    for (const m of seg.text.matchAll(SHADOW)) {
      push(base + m.index!, m[0], "off-scale", "shadow", m[1]!, offScale(scale?.shadowKeys, m[1]!), `Shadow ${m[0]} isn't one of your shadow roles.`, `Use ${list("shadow-", scale?.shadowKeys)}.`);
    }
    for (const m of seg.text.matchAll(TIMING)) {
      push(base + m.index!, m[0], "raw-motion", "duration", `${m[2]}ms`, true, `Hard-coded animation timing ${m[0]}.`, `Use duration-(--motif-duration-base) (or fast/slow), or import { duration } from "${motionImport}".`);
    }
    for (const m of seg.text.matchAll(EASE)) {
      push(base + m.index!, m[0], "raw-motion", "easing", m[1]!, scale ? !scale.easeKeys.has(m[1]!) : true, `Default easing ${m[0]}.`, `Use ${list("ease-", scale?.easeKeys) || "ease-standard"}.`);
    }
    for (const m of seg.text.matchAll(FONT)) {
      push(base + m.index!, m[0], "raw-font", "font-family", m[1]!, scale ? !scale.textKeys.has(m[1]!) : true, `Default font ${m[0]}.`, "Use a font role class such as font-body.");
    }
  }
  return hits.sort((a, b) => a.line - b.line || a.column - b.column);
}
```

```ts
import { locator } from "../../text";
import type { SourceFile } from "../files";
import { makeHit, type Hit, type RuleId, type Scale, type ValueKind } from "../types";

export const IMPORTS_MOTION = /from\s+["'](?:motion|motion\/react|motion\/react-client|framer-motion)["']/;

const CSS_DECLARATION = /([a-zA-Z-]+)\s*:\s*([^;{}]+)/g;
const SPACE_PROP = /^(?:(?:margin|padding)(?:-(?:top|right|bottom|left|inline|block)(?:-(?:start|end))?)?|gap|row-gap|column-gap|inset(?:-(?:inline|block)(?:-(?:start|end))?)?|top|right|bottom|left)$/i;
const RADIUS_PROP = /^border(?:-(?:top|bottom|start|end)-(?:left|right|start|end))?-radius$/i;
const MOTION_PROP = /^(?:transition|animation)(?:-(?:duration|delay|timing-function))?$/i;
const LENGTH = /(?<![\w.-])(-?\d*\.?\d+)(px|rem)\b/g;
const TIME = /(?<![\w.-])(\d*\.?\d+)(ms|s)\b/g;
const EASING = /\b(?:ease(?:-in-out|-in|-out)?(?![\w-])|cubic-bezier\([^)]*\))/g;
const PRIMITIVE = /--motif-primitive-[\w-]+|\bprimitive\.(?:color|font|space|radius|shadow)\b/g;

const STYLE_LENGTH = /\b((?:margin|padding)(?:Top|Right|Bottom|Left|Inline|Block|InlineStart|InlineEnd|BlockStart|BlockEnd)?|gap|rowGap|columnGap|top|right|bottom|left|inset|borderRadius|border(?:Top|Bottom)(?:Left|Right)Radius|fontSize)\s*:\s*(?:(-?\d+(?:\.\d+)?)(?=\s*[,}\n\r])|(["'])(-?\d*\.?\d+)(px|rem)\3)/g;
const STYLE_FONT = /\bfontFamily\s*:\s*(["'`])([^"'`]+)\1/g;
const MOTION_TIME = /\b(duration|delay|visualDuration)\s*:\s*(\d*\.?\d+)/g;
const MOTION_SPRING = /\b(stiffness|damping|mass|bounce)\s*:\s*(\d*\.?\d+)/g;
const MOTION_EASE = /\bease\s*:\s*(\[[^\]]*\]|["'][\w-]+["'])/g;

const sizeMessages: Record<"space" | "radius" | "font-size", (px: number, steps: number[]) => [string, string]> = {
  space: (px, steps) => [`Spacing ${px}px isn't on your spacing scale.`, `Use var(--motif-space-<step>); your steps are ${steps.join(", ")}px.`],
  radius: (px) => [`Corner size ${px}px isn't one of your radius roles.`, "Use var(--motif-radius-<role>) or a rounded-<role> class."],
  "font-size": (px) => [`Text size ${px}px isn't one of your text roles.`, "Use var(--motif-font-<role>-size) or a text-<role> class."],
};

export function scanValues(file: SourceFile, scale: Scale | null): Hit[] {
  const at = locator(file.text);
  const hits: Hit[] = [];
  const push = (index: number, text: string, rule: RuleId, kind: ValueKind | undefined, value: string | undefined, violation: boolean, message: string, fix: string) =>
    hits.push(makeHit(file, at, index, { rule, ...(kind ? { kind } : {}), ...(value !== undefined ? { value } : {}), text, violation, message, fix }));

  const size = (index: number, text: string, kind: "space" | "radius" | "font-size", rawNumber: string, unit: string) => {
    const px = Math.abs(Number.parseFloat(rawNumber) * (unit === "rem" ? 16 : 1));
    const set = kind === "space" ? scale?.spacePx : kind === "radius" ? scale?.radiusPx : scale?.fontSizePx;
    const onScale = px === 0 || (set?.has(px) ?? false);
    const [message, fix] = sizeMessages[kind](px, [...(scale?.spacePx ?? [])].sort((a, b) => a - b));
    push(index, text, "off-scale", kind, `${px}px`, scale ? !onScale : false, message, fix);
  };
  const motionFix = `Use import { duration, easing, spring } from "${scale?.motionImport ?? "design/motion"}", e.g. transition={spring.smooth}.`;

  if (file.lang === "css") {
    for (const m of file.text.matchAll(CSS_DECLARATION)) {
      const prop = m[1]!.toLowerCase();
      const value = m[2]!;
      if (prop.startsWith("--")) continue;
      const start = m.index! + m[0].length - value.length;
      const kind = SPACE_PROP.test(prop) ? "space" : RADIUS_PROP.test(prop) ? "radius" : prop === "font-size" ? "font-size" : null;
      if (kind) {
        for (const l of value.matchAll(LENGTH)) size(start + l.index!, l[0], kind, l[1]!, l[2]!);
      } else if (prop === "font-family") {
        const family = value.trim();
        if (!/^(?:var\(|inherit|initial|unset)/.test(family)) {
          push(start, family, "raw-font", "font-family", family, true, `Hard-coded font ${family}.`, "Use var(--motif-font-body-family) or a font role class such as font-body.");
        }
      } else if (MOTION_PROP.test(prop)) {
        for (const t of value.matchAll(TIME)) {
          const ms = Number.parseFloat(t[1]!) * (t[2] === "s" ? 1000 : 1);
          if (ms > 0) push(start + t.index!, t[0], "raw-motion", "duration", `${ms}ms`, true, `Hard-coded animation timing ${t[0]}.`, "Use var(--motif-duration-fast), var(--motif-duration-base) or var(--motif-duration-slow).");
        }
        for (const e of value.matchAll(EASING)) {
          push(start + e.index!, e[0], "raw-motion", "easing", e[0], true, `Hard-coded easing ${e[0]}.`, "Use var(--motif-easing-standard), var(--motif-easing-enter) or var(--motif-easing-exit).");
        }
      }
    }
  } else {
    for (const m of file.text.matchAll(STYLE_LENGTH)) {
      const key = m[1]!;
      const kind = key === "fontSize" ? "font-size" : /Radius$/.test(key) ? "radius" : "space";
      if (m[2] !== undefined) size(m.index!, m[0], kind, m[2], "px");
      else size(m.index!, m[0], kind, m[4]!, m[5]!);
    }
    for (const m of file.text.matchAll(STYLE_FONT)) {
      push(m.index!, m[0], "raw-font", "font-family", m[2]!, true, `Hard-coded font ${m[2]}.`, "Use var(--motif-font-body-family) or a font role class such as font-body.");
    }
    if (IMPORTS_MOTION.test(file.text)) {
      for (const m of file.text.matchAll(MOTION_TIME)) {
        push(m.index!, m[0], "raw-motion", "duration", `${Number.parseFloat(m[2]!) * 1000}ms`, true, `Hard-coded Motion timing ${m[0]}.`, motionFix);
      }
      for (const m of file.text.matchAll(MOTION_EASE)) {
        push(m.index!, m[0], "raw-motion", "easing", m[1]!, true, `Hard-coded Motion easing ${m[0]}.`, motionFix);
      }
      for (const m of file.text.matchAll(MOTION_SPRING)) {
        push(m.index!, m[0], "raw-motion", "spring", `${m[1]} ${m[2]}`, true, `Hard-coded spring setting ${m[0]}.`, motionFix);
      }
    }
  }

  for (const m of file.text.matchAll(PRIMITIVE)) {
    push(m.index!, m[0], "primitive-use", undefined, undefined, true, `Uses a primitive value (${m[0]}) directly.`, "Use a role instead; primitives are building blocks for the design guide, not for code.");
  }
  return hits.sort((a, b) => a.line - b.line || a.column - b.column);
}
```

```ts
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { isMotifGenerated, sameContent, type GeneratedFile } from "../../generate/header";
import { locator } from "../../text";
import type { SourceFile } from "../files";
import { makeHit, type Hit } from "../types";
import { IMPORTS_MOTION } from "./values";

const MOTION_CONFIG = /reducedMotion\s*=\s*\{?\s*["']user["']|reducedMotion\s*:\s*["']user["']/;
const CSS_ANIMATION = /(?<![\w-])(?:transition|animation)(?:-[a-z-]+)?\s*:/;
const TW_ANIMATION = /(?<![\w-])(?:[\w-]+:)*(?:transition-(?:all|colors|opacity|shadow|transform)|animate-[\w-]+)(?![\w-])/;
const REDUCED_QUERY = /prefers-reduced-motion/;

export function reducedMotionHits(files: SourceFile[], generated: SourceFile[]): Hit[] {
  const everything = [...files, ...generated];
  const hits: Hit[] = [];

  const motionFile = files.find((f) => f.lang !== "css" && IMPORTS_MOTION.test(f.text));
  if (motionFile && !everything.some((f) => MOTION_CONFIG.test(f.text))) {
    const index = motionFile.text.search(IMPORTS_MOTION);
    hits.push(makeHit(motionFile, locator(motionFile.text), index, {
      rule: "reduced-motion",
      text: "motion",
      violation: true,
      message: 'Animations made with Motion ignore the "reduce motion" setting.',
      fix: 'Wrap your app once in <MotionConfig reducedMotion="user"> (from motion/react).',
    }));
  }

  const animated = files.find((f) => (f.lang === "css" ? CSS_ANIMATION : TW_ANIMATION).test(f.text));
  if (animated && !everything.some((f) => f.lang === "css" && REDUCED_QUERY.test(f.text))) {
    const index = animated.text.search(animated.lang === "css" ? CSS_ANIMATION : TW_ANIMATION);
    hits.push(makeHit(animated, locator(animated.text), index, {
      rule: "reduced-motion",
      text: "animation",
      violation: true,
      message: 'CSS animations ignore the "reduce motion" setting.',
      fix: "Run motif tokens and import its stylesheet (it includes the rule), or add an @media (prefers-reduced-motion: reduce) rule.",
    }));
  }
  return hits;
}

export function generatedEditedHits(root: string, expected: GeneratedFile[]): Hit[] {
  const hits: Hit[] = [];
  for (const f of expected) {
    const abs = join(root, f.path);
    if (!existsSync(abs)) continue;
    const text = readFileSync(abs, "utf8");
    if (!isMotifGenerated(f.path, text) || sameContent(text, f.content)) continue;
    hits.push({
      rule: "generated-edited",
      file: f.path,
      line: 1,
      column: 1,
      text: "",
      violation: false,
      message: "This generated file doesn't match your design guide: it was edited by hand or is out of date.",
      fix: "Change design/tokens.json instead, then run motif tokens.",
    });
  }
  return hits;
}
```

```ts
const byPosition = (a: Hit, b: Hit) => a.file.localeCompare(b.file) || a.line - b.line || a.column - b.column;

export function checkApp(root: string, app: AppInfo, theme: Theme, opts: { paths?: string[]; ignore?: string[] } = {}): AppCheck {
  const appDir = join(root, app.path);
  const srcDir = app.srcDir ?? chooseSrcDir(appDir);
  const scale = buildScale(theme, srcDir);
  const expected = generateReactWeb(theme, { srcDir, tailwind: detectTailwind(appDir) })
    .map((f) => ({ path: prefixPath(app.path, f.path), content: f.content }));

  const all = listSourceFiles(root, app.path, opts);
  const generated = all.filter((f) => isMotifGenerated(f.path, f.text));
  const files = all.filter((f) => !isMotifGenerated(f.path, f.text));
  const lines = new Map(files.map((f) => [f.path, f.text.split(/\r?\n/)]));

  const violations: Hit[] = [];
  const exceptions: ExceptionHit[] = [];
  for (const hit of [...files.flatMap((f) => scanFile(f, scale)), ...reducedMotionHits(files, generated)]) {
    if (!hit.violation) continue;
    const ex = exceptionFor(lines.get(hit.file) ?? [], hit.line);
    if (ex && "reason" in ex) exceptions.push({ ...hit, reason: ex.reason });
    else if (ex) violations.push({ ...hit, fix: `${hit.fix} (A "motif-ok" comment needs a reason, e.g. "motif-ok: required by the partner's brand guide".)` });
    else violations.push(hit);
  }
  return {
    app: app.path,
    files: files.length,
    violations: violations.sort(byPosition),
    exceptions: exceptions.sort(byPosition),
    warnings: generatedEditedHits(root, expected),
  };
}
```

```ts
const plural = (n: number, one: string, many: string) => `${n} ${n === 1 ? one : many}`;

function byFile(hits: Hit[], line: (h: Hit) => string): string[] {
  const out: string[] = [];
  let current = "";
  for (const h of hits) {
    if (h.file !== current) {
      current = h.file;
      out.push("", h.file);
    }
    out.push(line(h));
  }
  return out;

export async function runCheck(cwd: string, ctx: RunContext): Promise<CommandResult> {
  const tokensPath = join(cwd, "design", "tokens.json");
  if (!existsSync(tokensPath)) {
    return {
      command: "check",
      exitCode: 2,
      text: "No design guide found in this folder (missing design/tokens.json).\nDraft one from your code with motif extract, or start one with /design.",
      data: { error: "no-contract" },
    };
  }
  const { doc } = loadTokenDocument(TOKENS_JSON, readFileSync(tokensPath, "utf8"));
  if (!doc) {
    return { command: "check", exitCode: 2, text: "Your theme values file can't be read. Run motif validate to see why.", data: { error: "invalid-contract" } };
  }

  const detected = detectApps(cwd).apps;
  const apps = selectApps(detected, ctx.app);
  if (apps === null) {
    return { command: "check", exitCode: 2, text: `There's no app at "${ctx.app}". Apps here: ${detected.map((a) => a.path).join(", ") || "none"}.`, data: { error: "no-such-app" } };
  }
  const supported = apps.filter((a) => a.stack === "react-web");
  if (supported.length === 0) {
    const others = apps.filter((a) => a.stack).map((a) => `${appLabel(a)} (${STACK_LABELS[a.stack!]})`);
    return {
      command: "check",
      exitCode: 2,
      text: `motif check works on React web apps in this version.${others.length ? ` Found: ${others.join(", ")}.` : " No React web app was found here."} Support for more stacks is coming soon.`,
      data: { error: "unsupported-stack" },
    };
  }

  const theme = buildTheme(doc);
  const ignore = readIgnorePatterns(cwd);
  const results = supported.map((a) => checkApp(cwd, a, theme, { paths: ctx.positionals, ignore }));
  const violations = results.flatMap((r) => r.violations);
  const exceptions: ExceptionHit[] = results.flatMap((r) => r.exceptions);
  const warnings = results.flatMap((r) => r.warnings);
  const files = results.reduce((n, r) => n + r.files, 0);
  const filesWithProblems = new Set(violations.map((v) => v.file)).size;
  const allowed = exceptions.length ? ` (${exceptions.length} allowed with a reason)` : "";

  const lines: string[] = violations.length
    ? [`✗ ${plural(violations.length, "design problem", "design problems")} in ${plural(filesWithProblems, "file", "files")}${allowed}:`,
       ...byFile(violations, (h) => `  ${h.line}:${h.column}  ${h.rule.padEnd(18)} ${h.message} ${h.fix}`)]
    : [`✓ No design problems found in ${plural(files, "file", "files")}.${allowed}`];
  if (exceptions.length) {
    lines.push("", "Allowed with a reason:", ...exceptions.map((e) => `  ${e.file}:${e.line}  ${e.rule}  ${e.text} — motif-ok: ${e.reason}`));
  }
  if (warnings.length) {
    lines.push("", "Warnings:", ...warnings.map((w) => `  ${w.file}  ${w.message} ${w.fix}`));
  }
  if (violations.length) lines.push("", 'Fix these, or ask your agent: "fix the motif check findings".');

  return {
    command: "check",
    exitCode: violations.length ? 1 : 0,
    text: lines.join("\n"),
    data: {
      violations,
      exceptions,
      warnings,
      summary: { files, violations: violations.length, exceptions: exceptions.length, warnings: warnings.length },
    },
  };
}
```

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { stripBom } from "../text";

export interface TailwindDefaults {
  colors: Map<string, string>;
  spacingPx: number;
  radiusPx: Map<string, number>;
  textPx: Map<string, number>;
  easings: Map<string, string>;
}

const toPx = (value: string): number | null => {
  const m = value.trim().match(/^(-?\d*\.?\d+)(rem|px)$/);
  return m ? Number(m[1]) * (m[2] === "rem" ? 16 : 1) : null;
};

/** Tailwind v4 ships its default theme as CSS variables in node_modules/tailwindcss/theme.css. */
export function readTailwindDefaults(dirs: string[]): TailwindDefaults | null {
  for (const dir of dirs) {
    let css: string;
    try {
      css = stripBom(readFileSync(join(dir, "node_modules", "tailwindcss", "theme.css"), "utf8"));
    } catch {
      continue;
    }
    const d: TailwindDefaults = { colors: new Map(), spacingPx: 4, radiusPx: new Map(), textPx: new Map(), easings: new Map() };
    for (const m of css.matchAll(/--([\w.-]+)\s*:\s*([^;]+);/g)) {
      const name = m[1]!;
      const value = m[2]!.trim();
      if (name.includes("--")) continue;
      if (name.startsWith("color-")) d.colors.set(name.slice(6), value);
      else if (name === "spacing") d.spacingPx = toPx(value) ?? 4;
      else if (name.startsWith("radius-")) {
        const px = toPx(value);
        if (px !== null) d.radiusPx.set(name.slice(7), px);
      } else if (name.startsWith("text-")) {
        const px = toPx(value);
        if (px !== null) d.textPx.set(name.slice(5), px);
      } else if (name.startsWith("ease-")) d.easings.set(name.slice(5), value);
    }
    return d;
  }
  return null;
}
```

```ts
}

const distance = differenceEuclidean("oklab");

export function parseColor(value: string): Color | undefined {
  return parse(value.replace(/_/g, " "));
}

export function clusterColors(samples: Sample[], threshold = 0.03): { clusters: ColorCluster[]; unparsed: Sample[] } {
  const sorted = [...samples].sort((a, b) => b.count - a.count || a.value.localeCompare(b.value));
  const groups: { rep: Color; members: Sample[] }[] = [];
  const unparsed: Sample[] = [];
  for (const s of sorted) {
    const color = parseColor(s.value);
    if (!color) {
      unparsed.push(s);
      continue;
    }
    const group = groups.find((g) => distance(g.rep, color) <= threshold);
    if (group) group.members.push(s);
    else groups.push({ rep: color, members: [s] });
  }
  const clusters = groups
    .map((g) => {
      const contexts: Record<string, number> = {};
      for (const m of g.members) for (const [k, n] of Object.entries(m.contexts)) contexts[k] = (contexts[k] ?? 0) + n;
      const lch = toOklch(g.rep);
      return {
        hex: (formatHex(g.rep) ?? "#000000").toUpperCase(),
        count: g.members.reduce((n, m) => n + m.count, 0),
        contexts,
        members: g.members,
        l: lch.l ?? 0,
        c: lch.c ?? 0,
        h: lch.h ?? 0,
      };
    })
    .sort((a, b) => b.count - a.count)
    .map((c, i) => ({ id: `found-${i + 1}`, ...c }));
  return { clusters, unparsed };
}
```

| Role | Chosen from |
|---|---|
| `text-primary`, `text-secondary` | the 1st and 2nd groups most used as text that are readable (≥ 3:1) on the chosen background; if none are, the most used as text (secondary falls back to primary) |
| `background` | the group most used as a background |
| `surface`, `surface-raised` | the next background group with OKLCH chroma < 0.04, else `background` |
| `border` | the group most used as a border |
| `action-primary`, `focus` | the most-used group with chroma ≥ 0.08 |
| `success` / `warning` / `danger` / `info` | the most-used remaining saturated group within ±40° of hue 145 / ±25° of 75 / ±25° of 25 / ±30° of 245 |
| `action-secondary` | `surface`; `on-action-secondary` = `text-primary`; `text-inverse` = `background` |
| `on-*` | white or `#111827`, whichever contrasts more with the base colour |
| anything not found | Motif's defaults (the sample design guide's palette), reported in `roles` as `"default"` |

Dark values copy the light ones (and a note says so). Spacing uses the standard 4px scale; each observed value is reported with its nearest step. Radius `sm`/`md`/`lg` come from the observed values (1 value `v`: `round(v/2)`, `v`, `2v`; 2 values `a < b`: `a`, `b`, `round(1.5b)`; 3+: smallest, median, largest; none: 4/8/16). Text sizes: `body` = the most-used size between 14 and 18px (else 16), smaller sizes give `caption`/`label`, larger give `heading`/`title`/`display`, with ratio defaults (0.75, 0.875, 1.25, 1.75, 2.5) for gaps and each size kept larger than the previous. Durations: `fast`/`base`/`slow` = smallest/median/largest observed (defaults 120/200/320, capped at 2000 ms). `easing.standard` = the most-used easing (default `[0.2, 0, 0, 1]`). Shadows and springs use Motif's defaults.

```ts
export interface ExtractReport {

  spacing: unknown[];

  fontFamilies: Sample[];

const MAX_EXAMPLES = 5;

// ---------- collecting ----------

const KEYWORD_EASINGS: Record<string, number[]> = {
  ease: [0.25, 0.1, 0.25, 1], "ease-in": [0.42, 0, 1, 1], "ease-out": [0, 0, 0.58, 1], "ease-in-out": [0.42, 0, 0.58, 1],
  easein: [0.42, 0, 1, 1], easeout: [0, 0, 0.58, 1], easeinout: [0.42, 0, 0.58, 1], linear: [0, 0, 1, 1],
  in: [0.4, 0, 1, 1], out: [0, 0, 0.2, 1], "in-out": [0.4, 0, 0.2, 1],
};

function easingPoints(raw: string, tw: TailwindDefaults | null): number[] | null {
  const v = raw.replace(/["']/g, "").trim();
  const fromTw = tw?.easings.get(v);
  const text = fromTw ?? v;
  const nums = text.match(/^(?:cubic-bezier\(|\[)([^)\]]*)[)\]]$/)?.[1]?.split(/[,\s_]+/).filter(Boolean).map(Number);
  if (nums && nums.length === 4 && nums.every(Number.isFinite)) return nums;
  return KEYWORD_EASINGS[text.toLowerCase()] ?? null;
}

const bezier = (p: number[]) => `cubic-bezier(${p.join(", ")})`;

function cleanFamily(raw: string): string {
  const generic: Record<string, string> = { sans: "system-ui", serif: "serif", mono: "monospace" };
  if (generic[raw]) return generic[raw]!;
  return raw.split(",")[0]!.trim().replace(/^['"]|['"]$/g, "").replace(/_/g, " ");
}

export function collectOccurrences(files: SourceFile[], tw: TailwindDefaults | null): Occurrences {
  const buckets: Record<keyof Occurrences, Map<string, Sample>> = {
    colors: new Map(), space: new Map(), radius: new Map(), fontSize: new Map(), fontFamily: new Map(),
    duration: new Map(), easing: new Map(), unresolved: new Map(),
  };
  const add = (bucket: keyof Occurrences, value: string, hit: Hit, context?: string) => {
    const s = buckets[bucket].get(value) ?? { value, count: 0, contexts: {}, examples: [] };
    s.count++;
    if (context) s.contexts[context] = (s.contexts[context] ?? 0) + 1;
    if (s.examples.length < MAX_EXAMPLES) s.examples.push(`${hit.file}:${hit.line}`);
    buckets[bucket].set(value, s);
  };
  const sized = (bucket: "radius" | "fontSize", hit: Hit, table: Map<string, number> | undefined) => {
    const v = hit.value!;
    if (/^\d/.test(v)) return add(bucket, v, hit);
    const px = table?.get(v) ?? (bucket === "radius" && v === "none" ? 0 : bucket === "radius" && v === "full" ? 9999 : undefined);
    if (px !== undefined) add(bucket, `${px}px`, hit);
    else add("unresolved", hit.text, hit);
  };

  for (const file of files) {
    for (const hit of scanFile(file, null)) {
      switch (hit.kind) {
        case "color":
          if (hit.rule === "tailwind-palette") {
            const resolved = tw?.colors.get(hit.value!);
            if (resolved) add("colors", resolved, hit, hit.context);
            else add("unresolved", hit.text, hit);
          } else add("colors", hit.value!, hit, hit.context);
          break;
        case "space":
          add("space", hit.value!, hit);
          break;
        case "radius":
          sized("radius", hit, tw?.radiusPx);
          break;
        case "font-size":
          sized("fontSize", hit, tw?.textPx);
          break;
        case "font-family":
          add("fontFamily", cleanFamily(hit.value!), hit);
          break;
        case "duration":
          add("duration", hit.value!, hit);
          break;
        case "easing": {
          const points = easingPoints(hit.value!, tw);
          if (points) add("easing", bezier(points), hit);
          break;
        }
      }
    }
  }
  const sorted = (m: Map<string, Sample>) => [...m.values()].sort((a, b) => b.count - a.count || a.value.localeCompare(b.value));
  return {
    colors: sorted(buckets.colors), space: sorted(buckets.space), radius: sorted(buckets.radius), fontSize: sorted(buckets.fontSize),
    fontFamily: sorted(buckets.fontFamily), duration: sorted(buckets.duration), easing: sorted(buckets.easing), unresolved: sorted(buckets.unresolved),
  };
}

const DEFAULT_COLORS: Record<string, string> = {
  background: "#F9FAFB", surface: "#FFFFFF", border: "#D1D5DB", "text-primary": "#111827", "text-secondary": "#4B5563",
  "action-primary": "#4338CA", "action-secondary": "#E5E7EB", success: "#15803D", warning: "#B45309", danger: "#B91C1C", info: "#1D4ED8",
};
const WHITE = "#FFFFFF";
const INK = "#111827";
const STATUS: Record<string, [number, number]> = { success: [145, 40], warning: [75, 25], danger: [25, 25], info: [245, 30] };
const SPACE_STEPS: [string, number][] = [["0", 0], ["1", 4], ["2", 8], ["3", 12], ["4", 16], ["5", 20], ["6", 24], ["8", 32], ["10", 40], ["12", 48], ["16", 64]];
const FONT_ROLES: [string, number, number][] = [["display", 700, 1.1], ["title", 700, 1.2], ["heading", 600, 1.3], ["body", 400, 1.5], ["label", 500, 1.4], ["caption", 400, 1.4]];
const PAIRS: [string, string, string][] = [
  ["text-primary", "background", "text"], ["text-primary", "surface", "text"], ["text-primary", "surface-raised", "text"],
  ["text-secondary", "background", "text"], ["text-secondary", "surface", "text"], ["text-secondary", "surface-raised", "text"],
  ["on-action-primary", "action-primary", "text"], ["on-action-secondary", "action-secondary", "text"], ["on-success", "success", "text"],
  ["on-warning", "warning", "text"], ["on-danger", "danger", "text"], ["on-info", "info", "text"], ["focus", "background", "ui"],
];

const px = (value: number) => ({ value, unit: "px" });
const ms = (value: number) => ({ value, unit: "ms" });
const pxOf = (s: Sample) => Number.parseFloat(s.value);
const hueDistance = (a: number, b: number) => Math.min(Math.abs(a - b), 360 - Math.abs(a - b));

function srgb(hex: string) {
  const n = (i: number) => Number((Number.parseInt(hex.slice(i, i + 2), 16) / 255).toFixed(4));
  return { colorSpace: "srgb", components: [n(1), n(3), n(5)], hex: hex.toUpperCase() };
}

function onColor(hex: string): string {
  return wcagContrast(WHITE, hex) >= wcagContrast(INK, hex) ? WHITE : INK;
}

export function buildDraft(occ: Occurrences): { tokens: Record<string, unknown>; report: ExtractReport } {
  const { clusters, unparsed } = clusterColors(occ.colors);
  const used = (c: ColorCluster, k: string) => c.contexts[k] ?? 0;
  const by = (k: string) => clusters.filter((c) => used(c, k) > 0).sort((a, b) => used(b, k) - used(a, k) || b.count - a.count);
  const text = by("text");
  const backgrounds = by("background");
  const borders = by("border");

  const chosen: Record<string, ColorCluster | undefined> = {};
  chosen.background = backgrounds[0];
  // Text must be readable on the background: white text used on buttons isn't the main text colour.
  const readable = text.filter((c) => !chosen.background || wcagContrast(c.hex, chosen.background.hex) >= 3);
  const textPick = readable.length > 0 ? readable : text;
  chosen["text-primary"] = textPick[0];
  chosen["text-secondary"] = textPick[1] ?? textPick[0];
  chosen.surface = backgrounds.find((c) => c !== chosen.background && c.c < 0.04) ?? chosen.background;
  chosen.border = borders[0];
  const saturated = clusters.filter((c) => c.c >= 0.08);
  chosen["action-primary"] = saturated[0];
  const remaining = saturated.filter((c) => c !== chosen["action-primary"]);
  for (const [role, [hue, width]] of Object.entries(STATUS)) {
    chosen[role] = remaining.find((c) => hueDistance(c.h, hue) <= width && !Object.values(chosen).includes(c));
  }

  // Primitive colours: one per cluster used, plus defaults, white and ink.
  const primitives: Record<string, unknown> = {};
  const roles: Record<string, string> = {};
  const defaulted: string[] = [];
  const primitiveFor = (role: string): string => {
    const cluster = chosen[role];
    if (cluster) {
      primitives[cluster.id] = { $value: srgb(cluster.hex) };
      roles[`color.${role}`] = cluster.id;
      return cluster.id;
    }
    const name = `default-${role}`;
    primitives[name] = { $value: srgb(DEFAULT_COLORS[role]!) };
    roles[`color.${role}`] = "default";
    if (["success", "warning", "danger", "info", "action-primary", "text-primary", "background", "border"].includes(role)) defaulted.push(role);
    return name;
  };
  const hexOf = (name: string) => (primitives[name] as { $value: { hex: string } }).$value.hex;
  primitives.white = { $value: srgb(WHITE) };
  primitives.ink = { $value: srgb(INK) };

  const base: Record<string, string> = {};
  for (const role of ["text-primary", "text-secondary", "background", "surface", "border", "action-primary", "success", "warning", "danger", "info"]) {
    base[role] = primitiveFor(role);
  }
  base["surface-raised"] = base.surface!;
  base["action-secondary"] = base.surface!;
  base.focus = base["action-primary"]!;
  base["text-inverse"] = base.background!;
  base["on-action-secondary"] = base["text-primary"]!;
  for (const role of ["action-primary", "success", "warning", "danger", "info"]) {
    base[`on-${role}`] = onColor(hexOf(base[role]!)) === WHITE ? "white" : "ink";
  }
  roles["color.surface-raised"] = roles["color.surface"]!;
  roles["color.focus"] = roles["color.action-primary"]!;

  const color: Record<string, unknown> = { $type: "color" };
  const order = [
    "background", "surface", "surface-raised", "border", "text-primary", "text-secondary", "text-inverse", "action-primary",
    "on-action-primary", "action-secondary", "on-action-secondary", "focus", "success", "on-success", "warning", "on-warning",
    "danger", "on-danger", "info", "on-info",
  ];
  for (const role of order) {
    const alias = `{primitive.color.${base[role]}}`;
    color[role] = { $value: alias, $extensions: { "dev.motif": { modes: { dark: alias } } } };
  }

  // Spacing: the standard 4px scale.
  const space: Record<string, unknown> = { $type: "dimension" };
  for (const [key, value] of SPACE_STEPS) space[key] = { $value: px(value) };
  const nearestStep = (value: number) => SPACE_STEPS.reduce((best, step) => (Math.abs(step[1] - value) < Math.abs(best[1] - value) ? step : best));
  const spacing = occ.space.map((s) => {
    const v = pxOf(s);
    const [key, stepPx] = nearestStep(v);
    return { px: v, count: s.count, nearest: `space.${key}`, onScale: stepPx === v, examples: s.examples };
  });

  // Radius.
  const radiusValues = [...new Set(occ.radius.map(pxOf).filter((v) => v > 0 && v < 999))].sort((a, b) => a - b);
  let sm = 4, md = 8, lg = 16;
  if (radiusValues.length === 1) [sm, md, lg] = [Math.max(2, Math.round(radiusValues[0]! / 2)), radiusValues[0]!, radiusValues[0]! * 2];
  else if (radiusValues.length === 2) [sm, md, lg] = [radiusValues[0]!, radiusValues[1]!, Math.round(radiusValues[1]! * 1.5)];
  else if (radiusValues.length >= 3) [sm, md, lg] = [radiusValues[0]!, radiusValues[Math.floor((radiusValues.length - 1) / 2)]!, radiusValues[radiusValues.length - 1]!];

  // Type.
  const sizes = [...new Set(occ.fontSize.map(pxOf))].sort((a, b) => a - b);
  const bodySample = occ.fontSize.find((s) => pxOf(s) >= 14 && pxOf(s) <= 18);
  const body = bodySample ? pxOf(bodySample) : 16;
  const smaller = sizes.filter((v) => v < body);
  const larger = sizes.filter((v) => v > body);
  let caption = smaller[0] ?? Math.round(body * 0.75);
  let label = smaller.length >= 2 ? smaller[smaller.length - 1]! : Math.round(body * 0.875);
  if (caption > label) [caption, label] = [label, caption];
  const heading = larger[0] ?? Math.round(body * 1.25);
  let title = larger[1] ?? Math.round(body * 1.75);
  if (title <= heading) title = Math.round(heading * 1.4);
  let display = larger.length >= 3 ? larger[larger.length - 1]! : Math.round(body * 2.5);

    duration: { $type: "duration", $value: { value: duration, unit: "s" } },

  });

        motifContract: 1,

      },

    duration: { $type: "duration", instant: { $value: ms(0) }, fast: { $value: ms(fast) }, base: { $value: ms(baseMs) }, slow: { $value: ms(slow) } },
    easing: { $type: "cubicBezier", standard: { $value: standard }, enter: { $value: [0, 0, 0, 1] }, exit: { $value: [0.3, 0, 1, 1] } },
    spring: { snappy: spring(0.25, 0), smooth: spring(0.4, 0.1), bouncy: spring(0.5, 0.3) },

  const unresolved = [...occ.unresolved, ...unparsed];

    motifExtract: 1,

    fontSizes: occ.fontSize,
    fontFamilies: occ.fontFamily,
    durations: occ.duration,
    easings: occ.easing,
    unresolved,
    notes,
  };
  return { tokens, report };
}
```

```ts
import { existsSync, mkdirSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { listSourceFiles } from "../check/files";
import type { CommandResult, RunContext } from "../cli/output";
import { detectApps, STACK_LABELS } from "../detect/stacks";
import { buildDraft, collectOccurrences } from "../extract/draft";
import { readTailwindDefaults } from "../extract/tailwind-theme";
import { isMotifGenerated } from "../generate/header";
import { appLabel, selectApps } from "../project/apps";
import { readIgnorePatterns } from "../project/settings";

export const DRAFT_PATH = "design/tokens.draft.json";
export const REPORT_PATH = "design/extract-report.json";

const plural = (n: number, one: string, many: string) => `${n} ${n === 1 ? one : many}`;

export async function runExtract(cwd: string, ctx: RunContext): Promise<CommandResult> {
  const detected = detectApps(cwd).apps;
  const apps = selectApps(detected, ctx.app);
  if (apps === null) {
    return { command: "extract", exitCode: 2, text: `There's no app at "${ctx.app}". Apps here: ${detected.map((a) => a.path).join(", ") || "none"}.`, data: { error: "no-such-app" } };
  }
  const react = apps.filter((a) => a.stack === "react-web");
  if (react.length === 0) {
    const others = apps.filter((a) => a.stack).map((a) => `${appLabel(a)} (${STACK_LABELS[a.stack!]})`);
    return {
      command: "extract",
      exitCode: 2,
      text: `motif extract works on React web apps in this version.${others.length ? ` Found: ${others.join(", ")}.` : " No React web app was found here."} Support for more stacks is coming soon.`,
      data: { error: "unsupported-stack" },
    };
  }

  const ignore = readIgnorePatterns(cwd);
  const files = react
    .flatMap((a) => listSourceFiles(cwd, a.path, { ignore }))
    .filter((f) => !isMotifGenerated(f.path, f.text));
  const tw = readTailwindDefaults([...react.map((a) => join(cwd, a.path)), cwd]);
  const occ = collectOccurrences(files, tw);
  const { tokens, report } = buildDraft(occ);

  mkdirSync(join(cwd, "design"), { recursive: true });
  writeFileSync(join(cwd, DRAFT_PATH), JSON.stringify(tokens, null, 2) + "\n");
  writeFileSync(join(cwd, REPORT_PATH), JSON.stringify(report, null, 2) + "\n");

  const notes = [...report.notes];
  if (existsSync(join(cwd, "design", "tokens.json"))) notes.push("You already have design/tokens.json; it wasn't changed. Compare it with the draft.");

  const summary = {
    colors: occ.colors.length,
    colorGroups: (report.colors as unknown[]).length,
    spacing: occ.space.length,
    offScale: (report.spacing as { onScale: boolean }[]).filter((s) => !s.onScale).length,
    radius: occ.radius.length,
    textSizes: occ.fontSize.length,
    fonts: occ.fontFamily.map((f) => f.value),
    durations: occ.duration.length,
    unresolved: report.unresolved.length,
  };
  const text = [
    `✓ Draft theme values written to ${DRAFT_PATH} (from ${plural(files.length, "file", "files")}).`,
    `  Colours: ${summary.colors} found, grouped into ${summary.colorGroups}`,
    `  Spacing: ${plural(summary.spacing, "value", "values")}, ${summary.offScale} off a 4px scale`,
    `  Corners: ${plural(summary.radius, "size", "sizes")} · Text sizes: ${summary.textSizes} · Fonts: ${summary.fonts.join(", ") || "none found"} · Animation timings: ${summary.durations}`,
    ...notes.map((n) => `• ${n}`),
    `Next: review the draft (details in ${REPORT_PATH}). When it looks right, rename it to design/tokens.json and run motif validate.`,
  ].join("\n");

  return { command: "extract", exitCode: 0, text, data: { files: files.length, draft: DRAFT_PATH, report: REPORT_PATH, summary, notes } };
}
```
