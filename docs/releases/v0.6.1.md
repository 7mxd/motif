# Motif v0.6.1 (preview)

Motif works in Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI and OpenCode, for **React web** apps, **plain web** sites (HTML, CSS and JavaScript without a framework), **Vue** (and Nuxt), **Svelte** (and SvelteKit) and **Angular** apps, and **Flutter**, **Jetpack Compose**, **React Native with Expo** and **SwiftUI** apps ([what each stack gets](https://github.com/7mxd/motif/blob/main/docs/parity.md)). This preview fixes a Windows bug: Motif's screenshots and previews could, over many runs, stop copy and paste from working anywhere on the computer.

Motif keeps your app's design in a guide your agent follows, `DESIGN.md` and `design/tokens.json`. It shows mockups before code, screenshots your real app after, checks your code against the guide, and reviews the result in plain words.

## Install

**Claude Code**

```
/plugin marketplace add 7mxd/motif
/plugin install motif@motif
```

**Codex**

```
codex plugin marketplace add 7mxd/motif
codex plugin add motif@motif
```

**GitHub Copilot CLI**

```
copilot plugin marketplace add 7mxd/motif
copilot plugin install motif@motif
```

In VS Code, run "Chat: Install Plugin From Source" and enter `7mxd/motif`.

**Cursor:** add the plugin marketplace `7mxd/motif` in Cursor's plugin settings, or in the CLI run `cursor-agent plugin marketplace add https://github.com/7mxd/motif`.

**Gemini CLI**

```
gemini extensions install https://github.com/7mxd/motif --ref plugins --auto-update
```

**OpenCode, or any agent that reads `~/.agents/skills`**

- macOS and Linux: `curl -fsSL https://raw.githubusercontent.com/7mxd/motif/main/install.sh | sh`
- Windows PowerShell: `irm https://raw.githubusercontent.com/7mxd/motif/main/install.ps1 | iex`

The install script downloads the skill from this release, checks it against `SHA256SUMS` and puts it where OpenCode (or the shared `~/.agents/skills`) reads it. To read it first, download `install.sh` or `install.ps1` from the repository and run it from there.

Then start Motif: `/motif:design` in Claude Code, `$motif` in Codex, `/motif` everywhere else.

You need git, and Claude Code 2.1.224 or later if you use Claude Code. The first time Motif runs, it downloads its tool (about 100 MB) from this release and checks it against `SHA256SUMS`. Screenshots and previews use the Chrome or Edge you have; if you have neither, Motif asks before downloading a private browser (about 120 MB to download, about 300 MB on disk).

Motif runs on your computer. Previews and screenshots stay there, nothing is uploaded, and there's no telemetry.

Design sources are optional: `motif connect` sets one up (Motion, Refero, 21st.dev, 60fps.design) in each agent you pick, with any key typed only in your own terminal.

## What's new

**Copy and paste on Windows**

- Each time Motif started its browser (for `motif shot`, `motif preview` or the audit), it gave the browser a profile folder with a new random name. On Windows, Chrome and Edge register a name in a system-wide table for each profile folder they run in, and Windows keeps it until you sign out. The table holds about 16,000 names; after enough runs it filled, and copy and paste stopped working in every app until the next sign-out or restart.
- Motif now reuses a few numbered folders (`motif-browser-0`, `-1`, ...) in your temp folder, each emptied before the browser starts and removed after it closes, so the table gets one name per browser that ever ran at the same time as others, not one per run. Browsers running at once each get a folder of their own, and a folder left by a run that crashed is taken over.
- If copy and paste already stopped working, sign out of Windows or restart once: that empties the table, and Motif won't fill it again.

## Known limits

- Vue 2 and Nuxt 2, Svelte 4 and SvelteKit 1, and Angular 14 and older aren't supported. `motif doctor` says so. The CSS theme, `motif check` and `motif extract` still work there, and `motif shot --url` against an app you start yourself.
- Angular: when `angular.json` has several application projects, Motif reads the first and names it; name another by its folder in `design/motif.json`. An Nx workspace whose apps have no `package.json` of their own is read one app at a time, each named in `design/motif.json`. `motif shot` can't start an app without its own `package.json`: start it yourself and pass its address with `--url`.
- A redirect in a hash router (`/#/admin` to `/#/sign-in`) isn't noticed.
- `motif doctor` doesn't check that Node.js is new enough for the app's Nuxt (Nuxt 4.6 needs 22.22.3, or 24.15 or later); npm warns.
- Svelte's `Spring` follows the guide's springs at 60 frames a second. On a faster screen it is stiffer and bounces less; `motionSpring` in `motion.ts` is the same on every screen.
- `motif extract` doesn't read an UnoCSS theme. `motif check` reads a git submodule's files as the app's; leave them out with `ignore` in `design/motif.json`.
- On every web stack, one reduced-motion check anywhere in the app counts for the whole app.
- React Native without Expo isn't fully supported: theme code, checks and drafts work, and for screenshots you run the app on react-native-web and pass its address to `motif shot --url`. Expo screenshots come from the web target, so native-only components and platform fonts can look different.
- SwiftUI screenshots need a Mac with Xcode. Motif refuses a Swift package, an app that uses CocoaPods, and a project that uses files outside its folder, each with what to do.
- Jetpack Compose: Motif names the Compose library modules an app depends on but doesn't read them yet, and Compose Multiplatform isn't supported.
- Flutter variants change colours only: a variant's other roles (type, corners) use the default's, and `motif tokens` says which.
- A few of the starting styles' fonts cover Latin letters only: Zalando Sans (Bold), TASA Orbiter (Dark Tech's headings) and Public Sans (Trust). For Cyrillic or Greek, pick a pairing from the type pairings guide that covers them.
- Cursor's plugin install is checked by hand, not by the release checks: its CLI adds the marketplace, and installing the plugin happens in Cursor. The release checks add the marketplace on Windows and Linux only, since Cursor's CLI can't keep its sign-in on CI's macOS machine.
- Codex asks multiple-choice questions only in Plan mode; elsewhere Motif asks in a numbered list.
- The tool binaries aren't code-signed. The plugin downloads and checks them, so they run without a warning; a binary you download by hand may get one from macOS or Windows.
- Windows on ARM runs the x64 tool.

## Files

| File | What it is |
|---|---|
| `motif-claude-code.zip` | The Claude Code plugin, installed through the marketplace |
| `motif-skill.zip`, `motif-skill.tar.gz` | The skill alone, which `install.ps1` and `install.sh` download |
| `motif-windows-x64.exe`, `motif-darwin-arm64`, `motif-darwin-x64`, `motif-linux-x64`, `motif-linux-arm64` | The `motif` tool, downloaded by the skill when it's first needed |
| `SHA256SUMS` | Checksums of all of the above |
| `THIRD-PARTY-NOTICES.txt` | The licences of the other works Motif ships |
