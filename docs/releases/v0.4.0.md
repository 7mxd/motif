# Motif v0.4.0 (preview)

Motif works in Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI and OpenCode, for **React web** apps and **plain web** sites (HTML, CSS and JavaScript without a framework). This preview gives the eight starting styles fonts and colours of their own, adds an Arabic font to each, and steers new designs away from the look most agent-built sites share.

Motif keeps your app's design in a guide your agent follows, `DESIGN.md` and `design/tokens.json`. It shows mockups before code, screenshots your real app after, checks your code against the guide, and reviews the result in plain words.

## Install

**Claude Code**

```
/plugin marketplace add 7mxd/motif
/plugin install motif@motif
```

**Codex**

```
codex plugin marketplace add 7mxd/motif
codex plugin add motif@motif
```

**GitHub Copilot CLI**

```
copilot plugin marketplace add 7mxd/motif
copilot plugin install motif@motif
```

In VS Code, run "Chat: Install Plugin From Source" and enter `7mxd/motif`.

**Cursor:** add the plugin marketplace `7mxd/motif` in Cursor's plugin settings, or in the CLI run `cursor-agent plugin marketplace add https://github.com/7mxd/motif`.

**Gemini CLI**

```
gemini extensions install https://github.com/7mxd/motif --ref plugins --auto-update
```

**OpenCode, or any agent that reads `~/.agents/skills`**

- macOS and Linux: `curl -fsSL https://raw.githubusercontent.com/7mxd/motif/main/install.sh | sh`
- Windows PowerShell: `irm https://raw.githubusercontent.com/7mxd/motif/main/install.ps1 | iex`

The install script downloads the skill from this release, checks it against `SHA256SUMS` and puts it where OpenCode (or the shared `~/.agents/skills`) reads it. To read it first, download `install.sh` or `install.ps1` from the repository and run it from there.

Then start Motif: `/motif:design` in Claude Code, `$motif` in Codex, `/motif` everywhere else.

You need git, and Claude Code 2.1.224 or later if you use Claude Code. The first time Motif runs, it downloads its tool (about 100 MB) from this release and checks it against `SHA256SUMS`. Screenshots and previews use the Chrome or Edge you have; if you have neither, Motif asks before downloading a private browser (about 120 MB to download, about 300 MB on disk).

Motif runs on your computer. Previews and screenshots stay there, nothing is uploaded, and there's no telemetry.

Design sources are optional: `motif connect` sets one up (Motion, Refero, 21st.dev, 60fps.design) in each agent you pick, with any key typed only in your own terminal.

## What's new

**Starting styles**

- New fonts for six of the eight styles, chosen to read well at small sizes and to stay clear of the handful most agent-built sites use: Onest (Minimal), Zalando Sans with Zalando Sans Expanded for headings (Bold), Geologica with TASA Orbiter (Dark Tech), Merriweather Sans with Vollkorn (Warm), Noto Serif Display over Source Serif 4 (Editorial) and Public Sans (Trust). Soft and Playful keep Nunito and Fredoka.
- New colours for all eight, in light and dark. None is one of Tailwind's, shadcn's or Material's own values, light backgrounds stay out of the cream that generated sites favour, and each style's danger colour stays apart from its main colour. Every style still passes the readability checks.
- Shadows take a tint of each style's text colour instead of plain black, lighter in the flatter styles, and corners step more clearly from small to large.
- Design guides already made from a starting style keep their fonts and colours.

**Arabic**

- Every style has an Arabic companion second in its font lists: Readex Pro, Alexandria, Changa, El Messiri, Markazi Text, Mada, Rubik or Baloo Bhaijaan 2. Arabic words use it, Latin words keep the style's font, and apps download it only when a page shows Arabic.
- Mockups include the companions' Arabic letters, so Arabic text looks right offline too.

**New designs**

- A type pairings guide gives two or three checked pairings for each mood, each with an Arabic companion, and lists the fonts and colour looks to leave out unless the developer asks for them.
- When Motif sets up a new app, each design direction names its font pairing and why it suits the brief.
- Reviews mention "the default look" (the fonts and colours most generated sites share) as advice the developer can keep or ignore, never as a fault.

**Fonts in previews and theme code**

- `motif tokens` and previews read a font list up to the first system font: an Arabic companion counts, and fallbacks such as Roboto or Apple Color Emoji are no longer listed as fonts to install.
- Previews check each font against the letters it's used for, so a main font that fell back is named even when its Arabic letters loaded.
- Mockup headings use lining figures, so numbers in a serif with old-style figures stay even.
- The preview kit no longer includes Inter, Space Grotesk, Fraunces, DM Sans, Playfair Display, IBM Plex Sans, Archivo or Source Sans 3. A guide that uses one loads it from Google Fonts in mockups.

**Sturdier**

- On macOS and Linux, a preview's browser and every helper it started stop when Motif exits, so none is left writing into its temporary profile.
- If a downloaded tool fails its safety check, the message shows both checksums, or says that the release's list has no line for that file, so a report says what went wrong.

## Known limits

- React web and plain web only. Vue, Svelte, Angular, React Native, Flutter, SwiftUI and Jetpack Compose come later.
- A few of the new fonts cover Latin letters only: Zalando Sans (Bold), TASA Orbiter (Dark Tech's headings) and Public Sans (Trust). For Cyrillic or Greek, pick a pairing from the type pairings guide that covers them.
- Cursor's plugin install is checked by hand, not by the release checks: its CLI adds the marketplace, and installing the plugin happens in Cursor. The release checks add the marketplace on Windows and Linux only, since Cursor's CLI can't keep its sign-in on CI's macOS machine.
- Codex asks multiple-choice questions only in Plan mode; elsewhere Motif asks in a numbered list.
- The tool binaries aren't code-signed. The plugin downloads and checks them, so they run without a warning; a binary you download by hand may get one from macOS or Windows.
- Windows on ARM runs the x64 tool.

## Files

| File | What it is |
|---|---|
| `motif-claude-code.zip` | The Claude Code plugin, installed through the marketplace |
| `motif-skill.zip`, `motif-skill.tar.gz` | The skill alone, which `install.ps1` and `install.sh` download |
| `motif-windows-x64.exe`, `motif-darwin-arm64`, `motif-darwin-x64`, `motif-linux-x64`, `motif-linux-arm64` | The `motif` tool, downloaded by the skill when it's first needed |
| `SHA256SUMS` | Checksums of all of the above |
| `THIRD-PARTY-NOTICES.txt` | The licences of the other works Motif ships |
