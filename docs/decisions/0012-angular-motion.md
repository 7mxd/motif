# 0012 — Angular's motion

- Date: 2026-10-25
- Status: Accepted
- Context: `motif tokens` writes theme code for an Angular app (plan 2K, Task 3). Angular has two ways to animate. The old one is `@angular/animations` (`trigger()`, `state()`, `transition()` and `provideAnimations()`), which npm now marks deprecated ("Use `animate.enter` and `animate.leave` instead"). The new one, from Angular 20.2, is `animate.enter` and `animate.leave` in templates. These are compiler syntax, not directives: `animate.enter="cls"` or `[animate.enter]="expr"` adds classes to an element as it enters. Angular then waits for the longest CSS animation or transition on the element before it removes them. `animate.leave` does the same before it removes the element. `(animate.leave)="fn($event)"` hands the leave to code instead: `fn` gets an `AnimationCallbackEvent` with the element (`target`) and `animationComplete()`. If `animationComplete()` is never called, Angular removes the element after 4 s (`MAX_ANIMATION_TIMEOUT` changes that). The two can't be mixed in one component. These facts were checked on angular.dev and npm on 2026-10-25.

## Decisions

1. **The theme files are React web's.** An Angular app gets `motifCss`, `tailwindCss` (Tailwind 4) and `motionTs` from `cli/src/stacks/react-web/generate.ts`, unchanged. `src/styles/motif.css` and `src/styles/motif.tailwind.css` sit beside the global `styles.css`. `src/app/design/motion.ts` goes in the folder `ng new` makes for the app. Both follow `sourceRoot` from `angular.json`, and `themeDir` in `design/motif.json` wins. For the same guide, the files are byte for byte React web's.
2. **Enter and leave are CSS classes timed by Motif's variables.** A class written for `animate.enter` or `animate.leave` takes its timing from motif.css: `.fade-in { animation: fade var(--motif-duration-base) var(--motif-easing-standard) }`. Angular reads the computed animation, so the guide's duration decides when the class (or the element) goes. This needs no Angular-specific file.
3. **Springs and code use Motion's `animate()` with motion.ts.** motion.ts is React web's: `duration` in seconds, `easing` as cubic-bezier points, and `spring` as Motion's `{ type: "spring", visualDuration, bounce }`. Its spring export is named `spring`, not Svelte's `motionSpring`, so the file stays React web's. In a leave callback, `animate(event.target, { opacity: 0 }, spring.snappy).then(() => event.animationComplete())` runs the guide's spring, and Angular removes the element when it ends. `cli/test/angular-compile.test.ts` builds exactly this with `ng build` on Angular 21.2. When the app hasn't declared `motion`, `tokens` says how to add it.
4. **Nothing is generated for `@angular/animations`.** It is deprecated, and it can't be mixed with `animate.enter` and `animate.leave` in one component. Its timings are strings of milliseconds (`'200ms cubic-bezier(…)'`), and Motif would have to keep a third motion format alive for an API on its way out. An app that still uses it can read `var(--motif-*)` in its styles, or the values in motion.ts (× 1000).
5. **Angular 15 to 20.1 get the same files.** These versions have no `animate.enter`, so they animate with the CSS variables (class bindings and CSS transitions) and with Motion's `animate()` in code. Nothing in the files depends on the Angular version, so `tokens` writes them for every supported version and prints no extra note.

## Consequences

- Angular joins React web and Vue: one motion.ts with Motion's springs, which settle about 1.2 times later than Motif's model (decision 0011, item 7). A correction to that factor would change all three together.
- If `@angular/animations` is removed, nothing in Motif changes. If Angular adds a spring to `animate.enter`, motion.ts may grow an Angular-specific export, under its own decision.
- The guide's skill for Angular (Task 9) teaches `animate.enter` with a motif-timed class first, and Motion in `(animate.leave)` for springs.
