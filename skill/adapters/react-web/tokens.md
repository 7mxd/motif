# Theme code

What `motif tokens` writes for a React web app, how to wire it in once, and how components use the theme values.

## What motif tokens writes

| File | Holds |
|---|---|
| `src/styles/motif.css` | A CSS variable per role: `--motif-color-action-primary`, `--motif-space-4`, `--motif-font-body-size` and so on. Light values sit on `:root`; dark values apply under `prefers-color-scheme: dark` and on `[data-theme="dark"]`; `[data-theme="light"]` forces light. |
| `src/styles/motif.tailwind.css` | Tailwind v4 projects only. It imports `motif.css` and maps Tailwind's utilities to the roles. It also removes Tailwind's default colours, radii, shadows, text sizes, fonts and easings, so only the theme's exist. |
| `src/design/motion.ts` | `duration` (in seconds), `easing` (cubic Bézier arrays) and `spring` (Motion's `{ type: "spring", visualDuration, bounce }`). |

The source folder follows the project (`src/`, or `app/` when there's no `src/`), as recorded in `design/motif.json`.

Every generated file starts with a "Generated by Motif" line. Never edit them: change `design/tokens.json`, then run `motif tokens` again.

## Wiring it in, once

**A fresh starter.** Starters ship their own theme, which would override the design guide's, so remove it first:

- Next.js: in `src/app/globals.css`, delete the starter's `:root` variables, its `@theme inline` block, its `@media (prefers-color-scheme: dark)` block and its `body` rule, keeping only the imports. In `src/app/layout.tsx`, remove the Geist fonts: the `next/font/google` import, the `Geist(…)` calls and their class names on `<body>`.
- Vite: in `src/index.css`, delete everything except the imports, and empty `src/App.css` (or delete it and its import).

**Tailwind v4.** In the main CSS file (Next.js: `src/app/globals.css`; Vite: `src/index.css`), import `motif.tailwind.css` right after `@import "tailwindcss";`, with a path relative to that CSS file. In a Next.js project:

```css
@import "tailwindcss";
@import "../styles/motif.tailwind.css";
```

Importing it before Tailwind would let Tailwind's defaults win.

**Without Tailwind.** Import `motif.css` once, from the main CSS file or from the app's entry file.

`motif tokens` reminds you when this wiring is missing.

## Using the values

| Role | Tailwind | CSS |
|---|---|---|
| `color.background` | `bg-background` | `var(--motif-color-background)` |
| `color.text-primary` | `text-text-primary` | `var(--motif-color-text-primary)` |
| `color.action-primary` with `color.on-action-primary` | `bg-action-primary text-on-action-primary` | `var(--motif-color-action-primary)` |
| `color.border` | `border-border` | `var(--motif-color-border)` |
| `space.4` | `p-4`, `gap-4`, `mt-4` | `var(--motif-space-4)` |
| `radius.md` | `rounded-md` | `var(--motif-radius-md)` |
| `shadow.md` | `shadow-md` | `var(--motif-shadow-md)` |
| `font.body` | `font-body text-body` (the family, then the size with its line height and weight) | `var(--motif-font-body-family)` and `var(--motif-font-body-size)` |
| `easing.standard` | `ease-standard` | `var(--motif-easing-standard)` |
| `duration.base` with `easing.standard` | `transition` | — |

In TypeScript, import motion values from `@/design/motion`; everything else is a class or a CSS variable. `@/` is the import alias the Next.js starter sets up; in a project without one (the Vite starter), use a relative path such as `../design/motion`.

## Dark mode

Dark mode follows the system automatically. To offer a switch, set `data-theme="dark"` or `data-theme="light"` on `<html>` and remember the choice; remove the attribute to follow the system again.

Never use Tailwind's `dark:` variant for colours: the roles already change on their own.

## Fonts

`motif tokens --json` lists the theme's `fonts`: each family with the weights its roles use (fonts every computer has are left out). Load each one with its Fontsource package:

```bash
npm install @fontsource/inter
```

The package name is the family in lower case with hyphens for spaces: Inter is `@fontsource/inter`, Source Serif 4 is `@fontsource/source-serif-4`. Then import each weight once, in the root (Next.js: `src/app/layout.tsx`; Vite: `src/main.tsx`):

```tsx
import "@fontsource/inter/400.css";
import "@fontsource/inter/600.css";
```

The font files are served with the app, so nothing loads from Google when people use it.

Don't use `next/font` or the `@fontsource-variable` packages for theme fonts: both register the font under a different family name, so the theme's names wouldn't match and text would fall back.

## Tailwind v3

Motif writes the CSS variables only. Use them as `bg-[var(--motif-color-action-primary)]`, or upgrade to Tailwind v4 for the generated theme.
