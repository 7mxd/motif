# Supahero

Supahero is a free public gallery of landing-page hero sections, now part of ScreensDesign. It has no API or MCP server, so there is nothing to connect and nothing to detect.

## When to use it

Only when building a landing page or a welcome page, and only for its hero: the first screen people see. For anything else, use the UX pattern guides.

## How

1. Look at a few public hero pages in the gallery that match the brief's personality and category.
2. Note the structure, not the look: how long the headline is, where the main action sits, what proof appears (a screenshot, a number, a logo row), and how much space surrounds it.
3. Write the pattern down in your own words, and build an original hero from it with the guide's roles.
4. Keep the links you looked at in the guide's Direction section.

## Rules

- Its content is all rights reserved: never copy images, headlines or code.
- Build an original hero with the guide's roles and the app's own copy.
- Read [anti-patterns](../knowledge/anti-patterns.md) before you finish: heroes are where generated-looking design shows most (gradient text, glass panels, generic slogans).
